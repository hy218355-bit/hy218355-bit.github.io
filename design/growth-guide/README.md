# 育てる手応えと、副顧問の案内

作業ブランチは `codex/design`。元の共有チェックアウトは変更せず、pushしていない。

## 依頼への対応

1. **序盤の厳しさ**：演奏会は、できた音を基準に課題の割合で出来を下げる。少人数と初心者への固定減点が積み重なって、最初の音が一律0点になる状態を解消した。無音は0点。歓迎演奏の低い出来の文章も、吹ききったことと見学者の反応を伝える形にした。
2. **人選と育成**：全員が初心者の部と、育った部を乱す奏者を区別した。乱れの減点は20点へ滑らかに近づき、安定した厚みの加点は従来の最大4点。新人の60未満の基礎は最大30％身につきやすくし、60以上の伸び方と能力に応じた譜読みの速さは保つ。同じ編成の初心者5人を育てる対照検査で、音・厚み・大会点の回復を確認した。
3. **練習を工夫する価値**：検証用の手動指示を追加し、画面から選べる練習だけで比較した。基礎が弱いうちは表現より基礎を先にし、読めてまとまった上級者だけ個別の課題へ戻す。本番前の合奏と、新しい子の譜読み・合奏は残す。特定の部員の基礎を先に育てる効果を実計算で確認した。
4. **全曲・長期の確認**：全15曲を各10回、3年間進めた平均が目標範囲内。全15曲を別の3種類の初期乱数で各12年間進め、45試行すべて完走し、全曲で全国出場例があった。
5. **案内役**：オーナーが選んだ「若い副顧問」として、朝野先生を追加。最初の楽器決めから、選曲・練習・疲れ・合奏・人選・結果・年度末でひと言を変える。顔を押すと詳しい説明を開く。進行を止める表示や、自動で指示を変える処理はない。

## バランスの結果

自動の練習とおすすめ人選、指揮なし。15曲それぞれ10回の平均の範囲。

| 年 | 目標 | 調整後の県大会平均 |
| --- | --- | --- |
| 1年目 | 37〜47点 | 39.1〜46.2点 |
| 2年目 | 55〜67点 | 62.5〜66.9点 |
| 3年目 | 65〜75点 | 71.0〜74.4点 |

最初の歓迎演奏の平均は、調整前の全曲0点から、調整後は20〜23点になった。新人が増えた後の大会と、上級者の全国進出まで含めて調整した。大会の点は0〜100で単調に増え、中盤の進み方を整えつつ、仕上がった演奏は上位の点まで届く。

手動方針は、15曲全体の平均差が1年目約+0.45点、2年目約+0.01点、3年目約+0.1点。自動は十分に優秀で、毎週全員を操作するだけで大差がつくものではない。誰を先に育てるかは変えられ、基礎の弱い本人へ個別の指示を出す検査では、その人の基礎の伸びが増えた。今回の一つの方針がすべての状況で最善という検証ではない。

長期の全国初出場は7〜12年目。すべての試行で12年以内に出場したわけではなく、曲と入部・出来事で差がある。指揮、課題曲の選び直し、別の育成や人選による改善余地も残す。人間の楽しさを保証する検査とは分ける。

### 条件と記録

- `balance.json`：調整前、自動、手動の全15曲の平均と条件。`averages/`は実際の集計出力。新しい集計は、途中の失敗や3年分の結果不足があれば成功にしない（`average-guards.json`）。
- 平均の初期乱数は `SIM_SEED=202610290`、各試行の`SIM_RUN=1〜10`。出来事は最初の選択肢、相談は乱択、行事は適性優先、課題曲は先頭、冬は自動。
- 進行によって入部や乱数の消費が分かれるため、長期の平均との差を人選や一つの指示だけの因果効果とはみなさない。同じ編成での因果比較は`check_growth_balance.js`と`check_lineup_scoring.js`で行う。
- `long-term.json`：全15曲×3試行×12年。初期乱数は202610311〜202610313。`long-runs/`に全45試行の実際のログを保存。
- 再確認：`SIM_SEED=202610290 bash tsukurikata/tools/sim_avg.sh largo ode galop pomp aida hero holst hungarian flowers tell carmen valkyrie swan spring canon`。手動との比較は先頭に`SIM_POLICY=manual`を付ける。

## 画面・互換性・ビルド

- 375×812px、ライトとダークで確認。4タブ、案内の開閉、最初の部員、最初の練習、歓迎演奏、基礎の方針、人選を記録した。`screenshots/`は実際のブラウザのPNG。確認ページは保存と読み込みを起動前に止め、オーナーのセーブを使わない。
- 最終版のブラウザで2026年4月から2027年へ51操作進行。`new-year-final-dark.json`で完走、起動時の全34スクリプト取得、エラーなしを確認。コンソールは`console-final.json`。
- `checks/results.json`：40個のJavaScript検査すべて成功。新しい検査は、最初の音、無音、採点の単調性、初心者の育成と厚み、案内の16場面、保存済みの能力・録音・発表待ちの結果の保持、手動の実際の指示を確かめる。
- 部員の能力は引き続きG〜S。新しい保存項目は足さず、前の能力・録音・賞・点数を読み込みで書き換えない。案内の開閉は一時的なUIの情報だけ。
- 案内は静止画と標準の開閉。新しいアニメーション、毎回の顔生成、外部からの取得はない。原画1枚を使い回す。画像は141,506バイトで、制作と出典は`portrait-source.json`と`tsukurikata/img/CREDITS.md`。
- `glyph-check.txt`：表示する新しい文字の不足なし。残る10字は従来の記号5字とコメント内の5字。同梱のフォントを使い、新しいダウンロードはない。
- iPhone向けReleaseビルド成功。`native-check.json`で製品のHTML・主要スクリプト・案内役の絵・出典がアプリ内と一致することを確認。ミラーリングは使用しない。オーナーは外出中なので、実機への導入と画面・音の確認は後日。
