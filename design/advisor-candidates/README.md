# 副顧問の先生・追加の3候補

- A：短いボブと明るい笑顔。初めて遊ぶ人にも親しみやすい。おすすめ。
- B：まとめ髪と落ち着いた目元。合奏や本番で頼れる雰囲気。
- C：柔らかなウェーブ髪と穏やかな表情。相談や失敗した週にも寄り添う雰囲気。
- 比較用に、現在の眼鏡の朝野先生も並べた。

組み込みimage_genで、本作品向けに新しく描いた架空の若い副顧問。外部作品や素材は使っていない。生成の指定、原画の場所と変換の条件は`sources.json`。

原画は1254×1254px。画素数を保ってWebPへ圧縮し、3枚とも200KB以下。`index.html`に大きい顔と48pxのライト・ダークの見本を置いた。ブラウザで全画像の取得と375pxの横はみ出しなしを確認。`comparison.png`と`mobile.png`は実際のブラウザのPNG。

今回は候補の比較だけ。ゲーム本体、現在の先生の画像、部員、セーブには変更していない。オーナーが選んでから差し替える。ミラーリングとpushは行っていない。
