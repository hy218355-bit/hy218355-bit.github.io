# 顔で移動先を選ぶ

- 長い席名と交代相手を並べたプルダウンを、楽器のまとまりと顔つきの席ボタンへ変更。楽器の一覧は折りたたみ、選ぶと閉じる。
- 空席は楽器の印、控えは人の印。今の席は候補から外し、すでに控えの部員には控えの候補を出さない。
- 選んだ席は金の枠・チェック・aria-pressedで示す。再タップで解除、楽器を変えたときも未選択に戻す。決定ボタンはランクの予告の下に配置。
- 二人のランクの予告は従来どおり実際のmoveMemberの複製から作る。選択中は保存せず、未選択・本番中は移動不可。採点・成長・移動による能力の変化・保存形式は変更なし。
- チェックのSVGは自作。素材とフォントの取得なし。

## 確認

375×812のライトとダークで、選択・解除・楽器変更・交代・控え・空席・部員一覧・12文字の名前・Enterでの選択・本番中の決定不可を確認。選択中の状態は不変、交代・控え・空席の確定結果は全員の席・ランク・顔が予告と一致。横はみ出しと確認中のエラーなし。ブラウザの記録はbrowser-check.json。確認ページは本物のセーブを書き換えない。

顔と名前の既存回帰確認、JavaScriptの構文と差分、字形を確認。字形の不足は既存の記号5字のみ。PNGは375×812。
