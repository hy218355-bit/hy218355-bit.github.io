# 毎週、顔を見て育てる

## 変更

- 練習の一覧の下にあった体力の注意を、方針のすぐ下の顔一覧へ移した。体力30未満の部員だけを表示し、休む予定の子には休む印を添える。詳しい説明は「？」から読める。
- 顔を押すと、その子のパートと練習を開く。疲れの一覧からなら「休む」が先頭側に出る。選ぶまでは指示も能力も変えず、選択後・Escapeでは元の顔とスクロール位置へ戻る。
- 「よく伸びた」の名前の羅列を、上位3人の顔・名前・力のランクへ変えた。選ばれる条件は従来と同じ。上がったランクがあれば、その力を優先して前後を表示。同じランクの中で伸びたときは、今のランクだけを見せる。
- 成長した子の顔からも次の練習を選べる。対応待ちのできごとで練習できない間は、押せそうなボタンにはせず顔と成長を表示する。
- 39人が疲れている場合も顔一覧は高さ166px以内でスクロールする。名前は読み上げと操作のラベルに全文を残す。新しい顔の操作は48px以上、説明は44px。能力の数値や途中の進捗は出さない。

変更はCSSとUIのみ。練習前の個別能力は`U.weekRes`の一時的な写しで、セーブ形式は変更しない。点数・成長・指示の効果・顔の配役はそのまま。外部素材・フォントの取得なし。

## 確認

実ゲームと同じ画面とスクリプトを使い、確認ページだけはセーブと設定の保存を止めている。最終版は`qa-practice-faces-3`。

- 375×812のライト・ダークで顔一覧・本人の練習・成長を確認。4タブとも内容幅375px。
- 前と後ろのパートへ顔から移り、本人の練習だけが開く。開く・閉じる操作の前後で部の状態のハッシュが一致。「休む」の決定では指示だけが変わり、能力はそのまま。
- Enterで顔から移れる。Escapeと選択後は、押した顔のボタンと元の画面位置へ戻る。成長の読み上げにも名前と前後のランクを含む。
- 実際に1週進め、音程F→D・リズムE→D・音色D→Cを表示。対応待ちのできごとの間は静かな表示、答えた後は練習を開ける。
- ランクBの中で伸びた見本では、前後の矢印を出さずBのみ表示。
- 39人全員が疲れた場合、12文字の名前、控え、320×568を確認。最後の子を開け、「休む」が画面内、下の進行ボタンとも重ならない。
- 演出「ふつう」の移動も確認。移動の動きは既存の`fxCalm`と演出設定に合わせ、短く・なしでは即座に移る。
- 初年度を実際のボタン69操作で、2026年4月から2027年4月まで進行。成長の顔が出る24場面も通過。画面のエラー・横はみ出しなし。コンソールの警告・エラー0件。
- 顔100人、舞台の顔と楽器、個人録音の停止、卒業の保存と移動の既存チェックが成功。構文・差分の確認も成功。字形チェックは既存の不足記号5字のみ。

`browser-check.json`に状態・指示・能力・録音の比較と各場面、`year-flow.json`に年度の操作、`tabs-check.json`に両テーマの4タブを保存。画面の画像は`screenshots/`。
