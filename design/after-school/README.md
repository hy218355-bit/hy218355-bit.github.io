# 放課後の音楽室：ゲーム画面と顔の再提案

LP②の改善版についてオーナーから「いい」と返事があり、その方向でゲーム画面と顔の案を作ることに「はい」と返事を受けた。ここでは**提案だけ**を作る。ゲーム本体への反映はまだ承認されていない。

## 開く

worktreeのルートで `python3 -m http.server 8001 --bind 127.0.0.1` を実行。

- `http://127.0.0.1:8001/design/after-school/`：4画面・顔・アイコンの一覧。
- `?screen=week&theme=light`：今週。`stage`・`member`・`grad`で合奏・部員カード・卒業式。
- `theme=dark`でダーク。
- `?screen=pair&view=week`：375pxのライトとダークを並べる。
- `?screen=reference`：画像生成で作った12人の絵柄見本。
- `?screen=faces`：別に自作したSVGパーツの12人と表情。
- `?screen=pair&view=member&faces=svg`：同じ部員カードをSVG試作で表示。

## 顔の2種類を混同しない

**画面に最初に出る顔は、絵柄確認用の画像を仮に配置したもの。製品に入れる顔ではない。** 新しい絵柄と画面の相性を見てもらうため、LPの絵を参照して制作した12人を載せた。画像を名前から選んだり、性別を推測したりしていない。仮の対応は、この見本の12人だけに固定。40人への種類数や表情切り替えを満たす実装とは扱わない。

SVGパーツ版は `faces.js` と `assets/faces/member-01.svg`〜`member-12.svg`。原画の絵を埋め込んだものではなく、輪郭・髪・目・眉・口・ほお・小物を別のSVGで描いた軽量化の試作。**原画より大幅に描き込みを省いており、同じ質感にはまだ届いていない。** 画面の見本、絵柄の好み、SVGで残す描き込みを確認し、顔は別途OKをもらう。

## 顔の年齢感の修正（2版）

「1年生から3年生まで共通だから少し大人すぎる」という指摘を受け、絵柄見本を `assets/faces-art-direction-v2.webp` に更新した。頬と顎を柔らかくし、顔の縦の長さと鼻・目元の陰影を控えめにした。1年生にも自然で、3年生としても使える共通の年齢感を狙う。前の12人の並び、髪型、紺の制服、夕日の光は保持し、首の後ろに手を添えた姿勢は自然な姿勢へ変更した。

これは絵柄確認用の画像の修正だけで、SVG試作の年齢感や描き込みは未修正。ゲーム本体も未変更。前の原稿は残した。生成記録は `assets/faces-art-direction-v2.prompt.txt`。画像は1440×1080、193,950 bytes。

4画面の仮配置と撮影を更新。375px・ライト／ダークの8画面で横幅375pxを確認（`screenshots/age-v2-viewport-checks.json`）。連続撮影時に、前回と同じ発生元URLのないMutationObserverエラーが記録された。顔の画像の参照先以外、ゲーム画面の構造や動作は変更していない。

## 顔立ちの違いの見直し（3版）

オーナーから「顔似てる」と指摘されたため、`faces-v3.html` に顔立ちの異なる12人を新規制作した。1〜3年生共通の若さは維持し、輪郭の幅と長さ、頬と顎、目の形と間隔、眉、鼻、口を個別に指定。正面寄りで目を開いた穏やかな表情を並べ、髪型や表情だけに依存しない違いを比較する。

`assets/faces-art-direction-v3.webp` は1440×1080、194,144 bytes。組み込みimage_genを使用し、最終見本は参照画像なしの新規生成。プロンプトと原稿の場所は同名の `.prompt.txt`。前の顔を参照した途中の案は表情差が中心になったため、採用見本には使用していない。

見本ページは375pxのライトとダークで横幅375px、画像の読み込みとテーマ切り替えを確認。ブラウザの警告・エラーなし。32pxの表示も併記した。PNGは `screenshots/faces-v3-*.png`。ゲーム本体・SVG試作・四画面の仮配置は変更していない。顔の方向の承認を待つ。

`check_glyphs.py` も実行し、同梱Zenの3ウェイトで既存ゲームの未収録文字10個（▶♩♮⤓円因案混錐𝄪）を報告した。今回ゲーム側の文字・フォントは未変更で、ダウンロードやフォント再生成は行っていない。

## SVGの組み立て

- 既存 `util.js` の `hash(id, FACE_SEED, パーツ名)` を読み取り参照。名前・性別・セーブは入力にしない。
- 髪型12、髪色6、肌4、目5、目の色5、眉4、口4、輪郭4、服3。眼鏡・ヘアピンは18通り中2通りだけ。
- 同じidと表情のSVGテンプレートはキャッシュ。再利用時はグラデーションの識別子だけを付け替え、同じ画面で衝突させない。
- 連続する40人の見本idでは40種類、1枚は最大4,233 bytes。確認結果は `face-checks.json`。
- 小さい表示は26〜27px、一覧想定36px、カード112px。疲れ・好調・緊張は目と口を変える。卒業時の変化は眉を控えめにする程度。

## 画面の方向

- LPの紺、夕日の金、落ち着いた紙色を共通にする。原画は画面の上部に小さく使い、練習の操作領域は平らな紙面にする。
- 今週の週送りは、下の4タブのすぐ上へ固定する案。人数が増えても操作が遠くならない。相談の文字とボタンが重ならないよう調整済み。
- 力は従来どおりG〜Sの文字と色。Sは金、上位ほど目立つ。能力値の数字は出さない。
- 部員カードでは顔を最も大きくし、音を聴くボタンは見える位置へ。
- 舞台の部員は点のまま。顔を入れない。
- 卒業式は4タブを外し、その人の音と思い出に集中する案。
- フォントは同梱のZen Kaku Gothic New 400／700、Klee One 600、Share Tech Mono。主見出しはZen 700へ。Delaは新たに使わず、ファイルの削除もしない。ダウンロードなし。
- 下タブ、音符、再生、ランク、相談の吹き出し、カード、ボタンの例を各画面に含める。
- 校章と音符のアプリアイコンを、LP・ゲーム上部のマークと同じ形から作る。1024pxと60pxは `assets/`。OSの角丸は実装時に任せる。

## 確認

- 今週・合奏・部員カード・卒業式を375×812のライト／ダークで確認。8画面の `scrollWidth=375`。
- 名前の行は高さ27pxの1行。今週の主ボタン下端732px、タブ上端742px。相談と主ボタンの重なりなし。
- 方針・練習選択・TIPS・タブ・テーマ切り替えを操作。新規タブでの表示とTIPSの操作では警告・エラーなし。連続撮影のタブでは発生元URLのないMutationObserverエラーが1件記録された。本モックには同APIの呼び出しがなく、新規タブでは再現しなかった。
- `node --check` で2つのJS、`git diff --check`を確認。
- 動きは追加せず、`prefers-reduced-motion`ではスクロールも即時。
- 実ゲームの点数・成長・出来事・セーブ・音・iOSは未変更。実ゲームを1年進める検証は、【2】の実装後に行う。
