# トランペットのアイコン・原画を作り直す

2026年11月2日。前のトランペット案はオーナーから形と品質について指摘を受け、採用を見送った。本案は前の画像の編集や再圧縮ではなく、組み込みimage_genで新しい原画から制作したもの。CLI不使用。

強い黄色の筆跡を抑え、落ち着いた金属の反射と紺色の布でまとめた。3本のピストンとベルを大きく見せる近景へ変更し、譜面の文字や細かい背景をなくした。原画・256px・60pxで、3本のボタン、繰り返し部品の間隔、ベルの輪郭、金属の反射、明暗の背景での見え方を目視確認した。メーカー写真との完全な一致を検証したものではない。

部品の名称とピストン式の説明は、[ヤマハの楽器解体全書](https://www.yamaha.com/en/musical_instrument_guide/trumpet/mechanism/)と[ピストン式の解説](https://www.yamaha.com/en/musical_instrument_guide/trumpet/mechanism/mechanism004.html)を参照。メーカーの写真や図版を保存・加工・画像生成の参照入力として使ってはいない。ブラウザはWork設定で利用できず、画面の表示検証は未実施。

- `icon.webp`：1024×1024、不透明なRGB、WebP品質94、172,744バイト。1254pxの生成原稿から縮小・書き出し。生成原稿は元の場所へ保持。
- `icon-256.png`・`icon-180.png`・`icon-64.png`・`icon-60.png`：同じ原画から書き出したRGBのPNG。
- `preview.png`：340pxの角丸表示と明暗の背景へ置いた等倍60px。スクリーンショットではない。
- `index.html`：確認用ページ。
- `prompt.txt`：組み込み画像生成に渡した最終プロンプト。
- `source.json`：元の原画の場所、書き出し条件、確認資料のURL。

ダウンロードや外部素材なし。前の案は不採用の履歴として残す。製品アイコンは変更していない。採用後に製品のPNGとクレジットをそろえる。pushはしない。
