# 席移動後の音と表示をそろえる

本人だけを試聴中に控えへ移すと、移動前の演奏が鳴り続け、本人だけのフィルターも残っていた。控えのカードには「全員の音にもどす」も出なかった。

移動時は古い再生と読み込み待ちを取り消す。停止後の最新の部から移動を決定し、控えになった人・空になったパートの試聴を全員へ戻す。再生用の古い演奏も無効にし、次に再生すると新しい編成を使う。選んだ部員のパートを表示していた場合は新しいパートへ切り替える。

カードの先頭と短い通知で移動完了を示す。控えでも試聴を絞っている場合は「全員の音にもどす」を出す。

## 確認

- 修正前の再現：本人だけで再生→控えへ移動後も再生中、本人だけの設定、戻すボタンなし。
- 修正後：移動で停止し、試聴と音の側も全員に戻る。再生し直した演奏に控えの部員は含まれない。
- 本人を別の楽器へ移した場合は、本人だけの有効な試聴を保持。再生し直すと本人の音は新しい打楽器の席に出る。
- 読み込み待ちで移した場合も取り消され、読み込み完了後に古い演奏が勝手に始まらない。確認ページだけで待ちを制御して確認した。
- 一人だけのダブルリードを控えへ移すと、空になったパートだけの試聴は全員へ戻る。
- 控えの本人を聴く設定を選び直しても、カードの「全員の音にもどす」で戻せる。
- 名簿から開いた部員をフルートから打楽器へ移すと、表示パートも打楽器へ切り替わる。
- 375pxの両テーマと名簿からの操作で横はみ出しなし。確認中のエラーなし。保存済みの録音は移動前後で不変。
- JavaScript構文と差分の空白を確認。字形の不足は従来の記号5字のみ。
- iPhoneへビルド・インストール・起動し、最終のHTMLとUIが同梱内容と一致。

ゲームの採点・成長・楽器を変えるときの能力変化・保存形式は変更していない。新しい素材・フォントの取得なし。確認ページは本物の保存先を書き換えない。記録は `browser-check.json`・`iphone-build.json`、画像は375×812のPNG。
