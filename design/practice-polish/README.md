# 顔を見ながら決める、今週の練習

- 375pxの練習メニューをアイコン付きの2列へ。名前を省略せず、伸びる力も元の文言で表示。選択中は金の線・色・チェック。文字は本文色で読みやすくした。
- 練習と方針に、自作の息・チューニング・メトロノーム・休むアイコンと、既存の楽譜・部員・舞台・カレンダーを使用。SVGは文字色から色を受け継ぐ。
- 部員の行は30pxの顔と名前、G〜Sのランク。375pxでも名前と学年を1行に保つ。閉じたパートには本人の顔を最大3人添えた。
- 小人数の部でも、閉じたパートが選び直しで勝手に開かない。状態は年度とセーブの種ごとに分け、保存データには足さない。
- メニューを開くと選択中の項目にフォーカスし、下の進行ボタンを避ける。選ぶ・閉じる・Escapeで元の行とスクロール位置へ戻る。曲の練習範囲、A部門の配分、部の方針の操作位置も維持。
- 練習メニューは64px、現在の練習・方針・配分・まとめて選ぶ・練習範囲は44px以上の操作範囲。
- 点数・成長・おまかせの判断・練習の効果・セーブ形式・顔の配役は変更なし。素材やフォントのダウンロードなし。

- 閉じた別のパートは、指示を変えても閉じたまま。
- フルート4人への休む指示だけが入り、他の部員は変わらない。能力値も変化せず、まとめて選ぶボタンへ戻る。

- 4月から新年度まで49回の画面更新で2027年度へ進み、確認中のエラーなし。日誌の80件も全文を保持。
