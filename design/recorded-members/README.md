# 昔の録音の本人を表示する

録音の部員は `rec.snap.members` に保存されるが、顔の検索は `rec.members` を見ていた。現在の在籍一覧と卒業生一覧からも外れた部員は顔が出なくなっていた。既存の確認用データも実際と異なる `members` の形だったため、実際の保存形式へ直して失敗することを先に確かめた（`before-check.txt`）。

- 実際の保存形式から部員を読む。さらに `recPerf` で選んだ録音の部員を演奏に対応づけ、その録音の名前・学年・席・力を優先する。他の年の録音や現在の名簿と混ぜない。
- 対応づけはWeakMapだけで、音の情報やセーブには追加しない。演奏が不要になれば一緒に解放できる。
- 録音再生中の舞台からは当時のカードを開く。顔・当時の情報・G〜Sを見せ、本人の試聴と全員へ戻す操作を使える。改名や席移動は出さない。
- 別の録音、停止、現在の合奏、現在の名簿では録音用カードを解除し、今の部員の情報と混ざらないようにする。

## 確認

- 修正した `check_stage_faces.js` が成功。卒業生の保存形式、同じidの別の年の録音、現在の名簿の優先順位、元のセーブと演奏の不変、顔の間隔・タップと100人の画像の再利用を確認。
- 2031年の確認用の部で2026年と2027年の録音を再生。卒業生を含め39人の顔が出る。在籍していない本人のカードが開き、改名・席移動の操作は出ない。
- 同じidの部員を、2026年は「田中 七海」・3年・ピッコロ・A、2027年は「田中 葵」・3年・ピッコロ・D、現在は「田中 花音」・1年・打楽器・C〜Bとして区別。いまの名前や席は書き換わらない。
- 卒業生の本人だけの試聴と全員へ戻す操作、別の録音への切り替え、停止と現在の合奏、現在の名簿からの通常の編集を確認。
- 再生・カード操作の前後で元の部と録音の内容が不変。375pxの両テーマで横はみ出し・確認中のエラーなし。
- 名前・顔の既存チェックと構文・差分の空白を確認。字形の不足は既存の記号5字のみ。
- iPhoneへビルド・インストール・起動し、変更した実行ファイルの同梱内容を照合。実機の見た目はオーナー側で確認。

ゲームの採点・成長・録音の音・保存形式は変更なし。素材やフォントの取得なし。確認ページは本物の保存先を書き換えない。
