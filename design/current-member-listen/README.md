# 今いる部員の音を、今の演奏から聴く

昔の録音を再生しながら部員一覧を開き、「この人だけ聴く」を押すと、現在の部員のidで昔の録音を絞っていた。その録音にいない子は無音になり、同じidで残っている子も昔の力と楽器の音になった。修正前の実画面では小川悠斗を選んでも2027年の録音が続き、音の出る部員が0人。`before.json`に記録。

## 修正

今の部員カードの本人・パートの試聴を`listenCurrentMember`へまとめた。違う演奏を聴いていたら一度止め、現在の部から音を作って試聴する。現在の合奏を聴いている途中なら、再生位置を保って音を絞る。停止時に部が変わる場合もあるので、その後に本人と席を確かめる。

すぐ再生を押した場合は、予約した描き直しを再生ボタン側で行い、音と診断を作る。そのあとに同じ音をもう一度作って、現在の演奏との対応が外れないようにした。

録音の舞台から開く本人だけの試聴は、これまでどおりその録音の音を使う。部員・成長・採点・音づくり・保存済みの録音・セーブ形式は変えていない。画面の文章と顔の配役も追加・変更していない。

## 確認

- `check_current_member_listen.js`：実ゲームの現在と昔の部を作り、現在の本人・パートへ切り替わることを確認。同じidの昔の力、部が育った場合、現在の合奏を止めずに切り替える場合、停止時に席を外れた場合、セーブと録音の保持も確認。
- `check_live_performance.js`に、即時再生後の予約で同じ演奏を作り直さない確認を追加。既存の停止後の復帰、名前と録音の保持、舞台の顔の確認も成功。字形チェックは既存の不足記号5字のみ。
- 375pxのライト・ダークで操作。2027年の田中葵の録音は、録音のカードで聴くと同じ再生のまま本人だけになる。現在の部員一覧では改名・転向後の田中花音の今の音へ切り替わる。
- 昔の録音にいない小川悠斗も本人だけの音が出る。パート試聴では現在のフルート4人になる。現在の合奏内の本人・パートの切り替えは、再生のインスタンスが同じで途切れない。
- 昔の録音の読み込み待ち中に現在の本人を選び直しても、準備後は今の本人が鳴る。お手本を再生中の場合も現在の本人へ切り替わる。
- それぞれの試聴前後で部の状態と保存済み録音の指紋が一致。`browser-check.json`に音の出る部員・演奏全体の比較・再生の継続を記録。画像は375×812のPNG、1枚200KB以内。確認ページは本物のセーブ・設定を書き換えない。

ローカルの確認ページで一度、`FX`・`SEASON_OF`が読めていない起動エラーが出た。`preview-load-error.json`に保存し、一度の再読み込み後に上記の一連の操作を確認した。本修正でこの読み込みの問題が解消したとは主張しない。読み込みの原因は引き続き確認が必要。
