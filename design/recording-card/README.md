# 録音の顔から、本人と全員を聴く

## 見つかった不具合

録音の舞台から当時の部員を開き、「この人だけ聴く」を押して閉じると、カードが消えてもその人だけの音が残った。同じボタンを押し直しても全員へ戻らず、別の部員を開いても前の人だけが鳴った。`before.json`に実際の音の対象を記録した。

## 変更

- 本人と全員を同じボタンで切り替える。本人だけのときは金色の枠と「全員の音にもどす」、全員のときは「この人だけ聴く」。ボタンを作り直さず、操作先と録音の再生位置を保つ。
- 別の部員を開く、閉じる、Escape、自然終了で、そのカードの本人だけの指定を全員へ戻す。自分で選んだパート指定は保つ。待機中に閉じた場合も、読み込み後は全員で鳴る。
- カードを閉じたら舞台か名簿の元の操作へ戻す。自然終了では、消えるカード内に操作先がある場合だけ舞台へ戻し、別のボタンへ移った人の操作先を奪わない。
- Escapeは説明、名前の編集、席選び、カードの順に閉じる。録音カードには名前の編集欄がないためEscapeが効かなかった条件も直した。長押しと文字の変換中は次まで閉じない。

当時の顔・名前・学年・席・G〜Sの力はそのまま。音符・再生の時計・採点・成長・録音・セーブ形式を変えず、追加の素材・フォント・動く演出は入れていない。画面の説明文も増やしていない。

## 確認

- 実際の39人の録音で、本人→全員→本人→別の人→閉じるを操作。同じ再生idと演奏ハッシュを保ち、再生時刻が進むことを照合。一人だけのときはそのidだけ、全員では39人が音の対象になる。
- 同じidの今の部員が改名・席替えしていても、録音当時の名前・席・3年生・Aの力を表示。現在の名前を変える・席を移す操作は出さない。
- 読み込み待ちから本人を開いて閉じ、解放後に全員で鳴ることを確認。
- 自然終了で全員に戻り、操作先が舞台へ戻ることを短い区間の録音で確認。最初の全曲の確認では操作先がbodyへ落ちたため修正し、`end-finished`で修正後を記録した。
- 375×812・375×667のライト・ダークで横にはみ出さず、切り替えボタンは44px以上。原画の顔とG〜Sのランクを維持する。
- 実画面の改名のEscapeは編集欄だけ、席選びのEscapeは移動先だけを閉じ、その後にカードを閉じる。変更を保存せず、元の部を保つ。
- 4タブの横はみ出しなし。50操作で2027年度へ進行。33スクリプトの起動に成功し、コンソール警告・エラーなし。
- `check_recording_card.js`で全15曲の切り替え、部・音・録音の保持、同じ人・別の人・終了・待機・パートの扱い、説明と編集を優先するEscape、長押し・文字の変換中、舞台と名簿への操作先を確認。
- 個人録音、現在の部員、当日の舞台、選曲試聴の既存検証も合格。各`*-check.txt`に保存。
- 字の検査は既存の5記号（▶♩♮⤓𝄪）とコードコメントの「常」「了」を報告。今回の表示文言は本文の全3ウェイトに収録済み。

`browser-check.json`・`browser-assertions.txt`に観測と照合結果、`year-check.json`・`console-check.json`に進行と起動の結果を保存。
