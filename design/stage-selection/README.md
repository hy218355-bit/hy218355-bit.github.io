# 舞台で選んだ顔と楽器を見つけやすく

選択中の顔は、周囲を描き終えてから少し大きく重ねる。顔の輪郭と楽器の背景を、ライト・ダークそれぞれの文字色と紙色で描き、どの席を開いているか見つけやすくした。顔の半径は最大14pxで、舞台の大きさ・39席の位置・ほかの顔の大きさは変えていない。G〜Sの力の色も残す。

部員の照合は、描いている本人のidで行う。録音では当時の部員、本番では表示中の舞台の部員に印を付ける。カードを閉じると印も消える。新しい絵や画面の文章は増やしていない。音・採点・成長・保存の処理も変えていない。

## 確認で直したタップの境界

楽器の背景の最下部を押すと、下の列の部員を開く箇所があった。クラリネットの`cl1a`で再現し、隣の列の`asax1`の本人が選ばれたことを記録した。`seatAt`の判定の中心を顔と楽器の中間へ合わせ、顔と楽器をひと組で選べるようにした。楽器決めの点の座標と判定は変えていない。

## 確認結果

- 375pxの39席すべてで、顔と選択中の楽器の背景下端を実際にタップ。どちらも本人のカードと舞台の印が一致し、部の状態は不変。
- `check_stage_faces.js`に、楽器の背景下端の左右・中央で別の人を開かない確認を追加。240・309・343・720pxの全席で成功。既存の顔・楽器の中心の判定、録音の本人の顔、楽器決めの位置、画像の再利用も成功。
- 375pxのライト・ダーク、4タブで横はみ出しなし。選択を保ち、カードを閉じると印を消す。端の顔と楽器の背景が舞台に収まる。
- 320pxで12文字の名前の部員と右端の部員を選択。横はみ出しなし。控えの本人と空席には、別の部員の印を付けない。
- 昔の録音で、改名・席替え前の名前・3年・ピッコロの本人を選択。同じidの現在の名前・1年・打楽器と混ぜず、録音の舞台とカードに当時の本人を表示した。録音を作る従来の処理との演奏全体のハッシュも一致。現在の合奏へ戻すと今の本人へ切り替わる。
- 本番表示の舞台と部員カードでも本人が一致。閉じると舞台の印を消し、部の状態は不変。
- 個人録音の停止と現在の本人の試聴の既存確認が成功。構文・差分の確認に成功。33スクリプトの読込成功、画面とコンソールのエラーなし。
- 顔の原画は10枚・丸い画像は100個以内の既存の再利用を保つ。新しいアニメーションや描画のタイマーを足していない。追加した選択の印は静止表示で、演出の設定を変えない。
- iPhone用の署名付きReleaseビルド成功。変更したHTMLとui.jsが同梱内容とSHA-256で一致。実機iPhone 17は接続状態がunavailableで、今回はインストール・実機表示を未確認。
