# 演奏のつなぎ・威風堂々・新年度

選曲・楽器決め・合奏の診断から、いない楽器の審査や減点の説明を削除。人選で開く理由は受け持ちの説明にとどめ、楽器の採点自体は保った。

会場慣れは新年度も持ち越す。既存の毎週4ずつ減る処理は保つ。保存項目は増やさず、以前の年度更新ですでに消えた経験は推測して戻さない。

威風堂々は静かな前半を1.6倍に補い、30〜32拍で元へ戻す。後半の全合奏に一律の増幅を掛けない。直接音と残響を同じ倍率にし、指揮の音量操作とも両立させた。通常・保存した指揮・演奏中の指揮で補正する拍をそろえ、停止と自然終了で補正用ノードを片づける。

全曲で、つながる音の音色の明るさを滑らかに変える。スラーは25ms、それ以外のつながりは8msの時定数。最初の音と離れた音の立ち上がりは保つ。音源の追加・取り直しはせず、部員の音程やリズムのずれ、音符、採点、成長の式は変えていない。

## 実測

同梱の41音源とホールの響きを読み込み、実際の`renderPerf`で書き出した。能力100の39人・能力65の39人・能力65の5人で比較。比較曲は天国と地獄、歓喜の歌。前半と後半は32拍目で分けた。

| 威風堂々 | 前半 LUFS 修正前 → 後 | 後半 LUFS 修正前 → 後 | 最大ピーク dBFS 修正前 → 後 |
| --- | --- | --- | --- |
| お手本39人 | −28.2 → −24.5 | −13.1 → −13.1 | −1.5 → −1.5 |
| 能力65・39人 | −26.3 → −22.4 | −14.8 → −14.8 | −2.8 → −2.8 |
| 能力65・5人 | −29.2 → −25.3 | −19.5 → −19.5 | −7.3 → −7.3 |

前半は約4dB聴き取りやすくなり、後半と最大ピークは維持。比較した他の2曲も0.1dB単位で同じ。曲全体のLUFSは、静かな区間が測定のしきい値を越えると対象区間が変わるため、上表の区間ごとの値で評価した。実測は音量の確認であり、実機での聴感評価は別途必要。

`meter.html`を開き「比べる」で再測定できる。`loudness.js`は既存の`tools/loudness_console.js`のK特性測定関数を取り出したもの。確認ページはセーブ・設定を保存しない。修正前の計測は変更前のソースを一時フォルダへ固定して行った。結果は`loudness-before.json`・`loudness-after.json`。
