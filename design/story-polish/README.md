# 顔から伝わる相談と卒業式

- 相談は56pxの顔と大きな名前を見出しにし、学年・楽器・スキルも保持。話と返答は幅いっぱいへ広げ、返答ボタンは52px以上。元の会話と選択肢、効果は変更していない。説明は「？」へ。
- 相談後の様子にも同じ本人の顔を添えた。前の記録に名前がない場合は、文章だけでも表示できる。
- 卒業式は104pxの顔、楽器、入部時→今の4つのランク、最後のひとこと、思い出の順。コンクール・スキル・夢・入部の記録は折りたたみ、内容は保持。
- 下に「前へ」のSVGボタンを追加。前の部員へ戻って読み直せる。カード全面のタップで次へ飛ばす操作は外した。カードに触れる・キーを押す・スクロールする・記録を開くと自動送りを止める。下の「次へ」はそのまま使える。
- 演出なしでは切り替えの動きを止め、短くの設定では短い切り替え。動きを減らす端末の設定も維持。
- 卒業生一覧も48pxの顔と楽器、同じ4つのランクで統一。入部の記録がない場合は現在のランクを表示する。
- ゲームの点数・成長・出来事・セーブ形式・顔の配役は変更なし。新しい素材・フォントのダウンロードなし。

## 確認

- 375pxのライト/ダークで相談と卒業式、4タブを確認。横にはみ出さない。
- 相談の顔は56px、返答ボタンは52pxと約70px。返答の下端588pxに対し固定ボタンの上端679pxで、重ならない。元の説明も「？」から読める。
- 相談後にも顔が表示される。ゲームの処理は確認用の状態に対して実行し、実際のセーブは上書きしない。
- 卒業式の次の人→前の人で、本人のidが元に戻る。最初では「前へ」が無効。全15画面の最後に「4月へ（新年度）」が表示される。
- 自動送りが動いている状態で「部活の記録」を開くと停止。同じ人のまま読み続けられ、カードに触れただけで次の人に飛ばない。
- 演出なしで記録を開いた画面は、カード下端約715px・操作欄上端740px。切り替えのtransitionは0秒。
- 旧セーブ相当の入部時の記録がない部員も卒業式に表示できる。卒業生一覧を開くと4つの成長が見える。
- 4月から新年度まで49回の画面更新で2027年度へ進み、確認中のエラーなし。
- JavaScriptの構文、`check_faces.js`、`check_stage_faces.js`、`git diff --check` が成功。`check_glyphs.py` は既存の不足記号5字のみで、新しい不足なし。

詳細は `screenshots/checks.json`。iPhoneのビルド・インストールと同梱ファイルの照合は成功。端末がロック中だったため自動起動はできず、`iphone-build.json` に記録した。解除後にアイコンから開く。実機の見た目はオーナーが確認する。
