候補のカードとボタンは従来どおり使い、押した操作先を保つ。選択・人数の上限・試聴・採点・成長・録音・セーブ形式は変えていない。新しい画像・フォント・演出・ダウンロードはない。

- `check_ensemble_picked.js`で0〜8人、候補と同じ本人と順序、解除、8枠の保持、読み上げの人数と名前、控えと不在の除外、部と選択を変えないことを確認。

- 選択を外すと一覧から顔も消え、押した候補へ操作先を保つ。候補全体は描き直さない。部と録音のハッシュも変わらない。
