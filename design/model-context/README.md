# お手本と、いまの部を聴き比べる

## 見つかった不具合

自分の部員カードを開いてからお手本を再生すると、聴く対象の一覧に自分の部員名が残った。その人はお手本の演奏に含まれず、選ぶと無音になる。見出しは「試しに聴く曲」のままで、範囲と指揮も有効だった。`before.json`に実際に音の対象が0人になった状態を保存。

## 変更

- 聴き比べの見出しを「お手本」「いまの部」へそろえる。お手本を始めると前の自分の部員カードを閉じ、聴く対象は音のあるパートだけにする。
- お手本の範囲は全曲として表示。操作は「止める」「いまの音」の2つにし、「いまの音」から同じ曲を現在の部で試聴する。切り替え後は通常の範囲と指揮が使える。
- 読み込み待ちからの切り替えも同じ処理へ渡し、古いお手本を後から鳴らさない。自分で選んだパートは切り替え時に全員へ戻す。
- お手本を聴きながら会場を変更しても、聴き方には実際の会場を示す。再生のラベルから固定の会場名を省いた。
- 切り替えで消える「いまの音」に操作先を残さず、停止へ戻す。本人・パートの試聴でカードを描き直したときも、押したボタンへ操作先を保つ。

お手本の演奏を作る条件、音符・打楽器・採点・成長・部員・録音・セーブ形式は変えていない。お手本の舞台は従来の楽器と光を使い、現在の部へ切り替えたら本人たちの顔を表示する。パートの判定は演奏ごとに使い回す。素材・フォント・動く演出の追加、外部取得はない。

## 確認

- `check_model_context.js`で全15曲×再生・待機の30通りを確認。見出し・曲・全曲の範囲・指揮の制限・本人を混ぜない一覧・音のあるパート・停止と現在の部へ戻る表示・判定の使い回し・部と演奏の不変を照合。
- 選曲試聴の全15曲×2種類、録音の全15曲57範囲、録音カード、本人・パートの試聴、オーディションの既存検証も合格。各`*-check.txt`に保存。
- 実ブラウザで、自分のカードを先に開いてもお手本に本人名が出ず、前のカードも閉じる。名簿から開き直した場合もお手本の一覧へ本人名を混ぜず、その本人の試聴を押すと現在の本人の音へ戻る。
- お手本37人分→フルート4人分→現在の5人、別の曲のお手本39人分→現在の本人1人を確認。演奏ハッシュを期待した演奏と照合し、操作で部と録音を変えない。
- 会場を音楽室へ変えると実際のエンジンと聴き方が音楽室になり、再生ラベルに元の会場名が残らない。
- 最終版の読み込み待ちでは「お手本」から「いまの部」へ切り替わり、解放後は現在の5人だけを再生。舞台の顔も5人で、古いお手本が重なって鳴らない。停止すると試聴の印が消え、範囲と指揮が通常の表示へ戻る。
- 375×812・375×667のライト・ダーク、4タブで横はみ出しなし。50操作で2027年度へ進行。33スクリプトの起動に成功し、コンソール警告・エラーなし。
- 字の検査は既存の5記号（▶♩♮⤓𝄪）とコメントの「常」「了」を報告。今回の見出しは本文の全3ウェイトに収録済み。

`browser-check.json`は各操作直後の観測。前半の「いまの音」は通常の合奏へ切り替える実装だったため見出しは「試しに聴く曲」。本人の試聴では操作先がbodyへ落ちたので修正した。最終版の見出しと待機は`final-*`、本人の操作先は`member-button-focus`で確認。現在の部の画像と小さい画面の画像は最終版で撮影し直した。
