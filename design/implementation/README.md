## 変えたところ

- 紙色・紺・真鍮のライト／ダーク、カード、ボタン、下タブ、カレンダー、ランクの形を統一。見出しは既存のZen Kaku Gothic New 700、本文もZen、日誌はKlee One、数字はShare Tech Mono。Delaのファイルは保持。
- 承認された音楽室を同梱。長い導入と正式曲名・練習の説明はTIPSで読める。週送りは下タブの上、部員の音を聴くボタンは顔のすぐ下。
- 再生・停止・音符・星・保存・行事・タブ・校章を、currentColorの自作SVGにした。
- 女子35人／男子4人の39人の原画を、下塗り・輪郭・肌・髪・目・眉・口・ほお・小物のSVGパーツへ変換。顔の形の組を保ち、髪・肌・目・眉・口・ほおの色の差をidのhashで決める。ビットマップの埋め込みなし。原画より色面は簡略化している。
- 連続する39人の通し番号を、hashで並べた39種類の型に対応させる。代の境目でも同じ型を続けて使わない。一般の古いidもhashで対応。名前・性別・学年は入力にしない。セーブに情報を足さない。
- 部員カード112px、一覧32px、練習26px、相談36px、卒業式82px、引退する部員36px、指揮のカード54px。入部・楽器決めでも32pxの同じ顔を出す。疲れと好調は目の開きだけを変える。
- 必要な顔だけ読み込み、idと表情ごとのSVGをBlob画像として使い回す。画面にない古いキャッシュは160件を上限に解放する。1枚はSVG最大171,206 bytes、読み込み用JS最大171,292 bytes。
- 座席の位置を保ったまま、床・ひな壇・照明を描き、紺の幕に変更。部員の点は維持。カットインと結果発表を同じ色・字・SVGで揃えた。
- 演出「短く／なし」とprefers-reduced-motionに対応。「なし」と動きを減らす設定では卒業式の棒と自動送りも止める。
- Webの180px／64pxとiOSの1024pxを、承認された校章と音符のアイコンへ変更。透過なし。

`game.js`・`band.js`・`engine.js`・`conduct.js`・`instruments.js`・`pieces/` は元の `6f1957e` から差分なし。点数・伸び方・出来事・セーブの形は変えていない。

G〜Sの8段階とSの金色を維持。指揮カード、譜読み、部員の力の平均、アンサンブルの選択に残っていた能力の数値もランク表示へ揃えた。審査の点数は保持。新しい画面の文章は増やさず、説明はTIPSに収める。

原画・SVG・アイコンの出典は [ゲームのCREDITS](../../tsukurikata/img/CREDITS.md)。外部読み込みや新しいダウンロードなし。

## 確認

- 375×812のライト／ダークで、入部、今週、合奏、部員一覧、日誌、部員カード、相談、本番、結果発表、卒業式の20画面。すべて文書幅375px。最終記録は [final-checks.json](screenshots/final-checks.json)。
- 練習の名前の行は26pxで1行。部員カードの音を聴くボタンは上から209〜245px、週送りは697〜743px。相談とボタンの重なりなし。
- ブラウザ内で4月から翌年4月まで49回の状態更新。2027年度・部員8人・セーブv2へ到達し、最終試験のコンソールエラーなし。[year-check.json](screenshots/year-check.json)。
- 4タブ、TIPS、演出3設定を操作。TIPS幅300px。ふつう／短くではカットイン、なしでは重ね画面なし。光の回転アニメーションは追加していない。「なし」の卒業カードのtransitionも0秒で確認。[motion-off-final.json](screenshots/motion-off-final.json)。[motion-settings.json](screenshots/motion-settings.json)。
- `node tsukurikata/tools/check_faces.js`：39種類、40人の組み合わせ、39人の代の境目、名前・学年からの独立、セーブ不変、キャッシュ再利用と上限、SVG形式、容量、ランクの境界を確認。
- `node tsukurikata/tools/sim.js 1 auto galop best`：1年分を正常終了。
- JS構文、SVGのXML、画像容量、アイコンの寸法と透過なし、`git diff --check`を確認。
- `check_glyphs.py` で不足していた漢字を、端末内に残っていた既存のGoogle Fonts原稿から再収録。ダウンロードなし。本文3ウェイトの残りは既存の想定どおり `▶♩♮⤓𝄪` の5記号だけ。再生・保存の操作記号はSVG、楽譜の記号は端末の標準フォントにフォールバックする。
- `build_fonts.py` は同じPythonのfontToolsを呼ぶようにし、pyftsubsetのコマンドがPATHになくても同じ原稿から書き出せるようにした。
- iPhone実機では、依頼どおり実施していない。

画面確認専用の `qa.html`・`qa.js` は、製品のHTMLを生成し、実ゲームのCSS・JSで状態を再現するfixture。39人の在籍・本番・卒業式は確認用の状態。静止画では一時的な知らせを既読にし、ゲーム本体にはテスト用の入口を入れていない。1年の進行試験では実際のゲーム関数と画面描画を順に実行する。確認は独立した8003番ポートで行った。

進行試験で、入部により平均が下がった週に、前の平均との差分が負になってランク表示が止まる問題を発見した。表示値をGの範囲に収め、負の前回値では上昇の印を出さないように修正。点数・成長値は変更していない。画面の起動と記号の置換もDOMContentLoaded後に揃えた。
