## 現状から残すもの／改善するもの

現状を `http://localhost:8000/` で375px確認。ライトは確認用フレームの `data-theme=light`、ダークは `dark`。画面の4タブ、紙と紺・真鍮、手書き、液晶の数字、G〜Sの色はよい。部員が文字だけで、名前を覚える手がかりが少ない。縦の大きなタイトルと長い説明が操作より先に見え、毎週の指示まで視線が遠い。

おすすめは **A「音楽室の部活手帳」**。一言は「一人ひとりを覚える、わたしたちの部活」。暖かい紙と紺、余白と穏やかな丸角。部員の顔・声・成長を同じ手帳の中に置き、入部から卒業まで愛着がつながる。合奏は木の床と真鍮の光。舞台の小さな席は点を継続する。

**B「放課後のパレット」**：一言は「はじめてでも、気軽にさわれる部活」。ミントと白、丸いシールのような部品。初見の親しみやすさが最も強い。紙の日誌や本番の特別感はAより軽い。

**C「小さな演奏会」**：一言は「このメンバーで、舞台に立ちたくなる」。すみれ色と金、幕と光を連想する意匠。舞台と卒業の特別感に強く、日常の練習にも華やかさが残る。

## 部員の顔

`preview.js` の独立した見本。既存 `util.js` を読み取り利用し、`hash(id, 'face-preview-v1', パーツ名)` で決める。名前・性別を入力にしない。輪郭4、髪型10、髪色6、目4、眉4、口4、肌5、背景5、服4、小物2（約13%）を組み合わせる。12人の見本は id を固定。同じ部員の顔は画面を移っても変わらない。

疲れ・zone・freezeは目と口だけの変化。卒業は眉を少し落ち着かせる程度。練習行26px、一覧想定28〜40px、カード92px。顔のSVGはキャッシュする。実装時に `js/faces.js` に分け、既存の部員idに接続する。部員カード、一覧、練習行、相談、卒業、指揮カードのすべてに同じ顔を出す。セーブを変更しない。

## 色・アイコン・文字量

- 色見本は背景・紙・文字・補助文字・線・金・よい／注意／悪いの9色を、案ごとにライトとダークで指定。
- G→Sは灰・青・緑・黄緑・黄・橙・赤・金の順。Sのみ内枠を足し、上位ほど目立たせる。能力値の数字は出さない。
- タブと操作のSVGは自作し `currentColor` を使う。絵の固定色は顔のパーツとアプリアイコンの原稿に限る。ゲーム実装時には顔のパレットも名前付き定数にまとめる。
- Aアイコンは手帳＋真鍮の楽器、Bは楽器のシール、Cは舞台の光＋楽器。1024pxと60pxを用意。OSの角丸は実装時にOSへ任せる。比較ボード上だけホーム画面の角丸を模擬する。
- 画面内の長い説明は既存の文章をTIPSや折りたたみへ移す方針。モックの声・日付・思い出は表示例であり、ゲーム内の文章追加の提案ではない。
- 動きは本モックでは使わない。`prefers-reduced-motion` を尊重。実装時には既存「演出：ふつう／短く／なし」に接続する。
