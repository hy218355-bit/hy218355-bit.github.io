# 自分たちの結果と、顔の見える日誌

- 結果発表で、自分の学校の賞を27pxへ。録音に出た本人の顔を最大8人添えた。録音が指定されていない場面は、実際に出場するメンバーから表示する。
- 大会名はスクロールの外へ、「結果を見る」は幅いっぱいの46pxのボタンに。学校の一覧の左の余白を除き、375pxでも顔8人を1行に並べた。
- 学校の発表順・賞・代表の判定・読み上げの順番と時間は変更なし。賞や代表を先に知らせる文章は追加していない。短く・なし・端末の動きを減らす設定を維持。
- 日誌は同じ日付の記録をまとめる。部員の出来事を見出しにし、開くと文章の続きと同日の残りを読める。表示対象は従来と同じ最新80件。元の文章は一字も落とさず、セーブのログも変更していない。
- 顔は、現在の部員・卒業生・録音の本人をフルネームで確かめて表示。同姓同名の別人や、名前が一致しない記録はアイコンを使う。名前の一部分だけで顔を推測しない。
- 開いた日付は、画面の再描画でも維持。開閉の状態はセーブに保存しない。
- 点数・成長・出来事・セーブ形式・顔の配役は変更なし。新しい素材・フォントのダウンロードなし。
