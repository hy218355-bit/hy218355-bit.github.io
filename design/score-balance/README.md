# 大会の採点係数の調整

2・3年目に点が高くなりすぎる曲の `ceiling` を調整。星の難しさとは別の調整。音符・音量・演奏のずれ・成長・譜読みの時間・人選の減点と厚みの加点・賞の基準は変更していない。

## 比較条件

- 調整前は `67d25f7` の全15曲の記録（`before.json`）。各曲10回、3年、自動練習・おすすめの人選・指揮なし。
- 同じ入部条件の種 `20261026`、実行番号1〜10で比較（`final-a.txt`・`final-b.txt`）。
- 重ならない別の種 `20260101`、実行番号1〜10でも全15曲を確認（`final-validation-a.txt`・`final-validation-b.txt`）。
- 両方とも、全曲の各年平均が目安の範囲内。1年目37〜47点、2年目55〜67点、3年目65〜75点。個々の部や本番の点をこの範囲に固定する仕組みは入れていない。
- 自由曲の係数を変えると、それが課題曲に選ばれた年にも効く。賞による評判、その後の入部にも自然な差が出るため、3年目の結果は係数に比例するだけではない。

## 保存と回帰確認

`check_score_balance.js` で全15曲・能力25/65/100を比較し、演奏の音・分析・演奏会の出来・同じ週の練習が係数変更で変わらないことを確認。県・支部・全国での採点が逆に上がらないこと、保存済みの録音・大会の点・賞・発表待ちの結果を読み込みで保つことも確認。

譜読み・人選・厚み・入部・名前の回帰確認も記録。製品の画面の文章は変更していない。

字形チェックは従来からの不足5字（▶・♩・♮・⤓・𝄪）を報告。今回の変更による追加はない。フォントの取得や作り直しはしていない。
