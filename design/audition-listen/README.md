# 選んだ人と全員を、人選を変えずに聴き比べる

## 再現した問題

先に部員カードで本人だけを聴いた後、人選の「このメンバーで聴く」を押すと、その本人だけの指定が残った。39人と表示していても実際には一人しか鳴らなかった。別の候補のオーディションを聴くと無音になった。

チェックを変えて38人にしても、以前の39人の演奏がそのまま鳴り続けた。`before.json`に実操作の表示・再生対象・人選を記録している。

## 改善

- 試聴を`listenAudition`にまとめ、前の再生を終えてから本人・パートの指定を外す。本人のオーディションは、保存されている当日の調子を使った既存の一節を鳴らす。
- 「選んだ人数で聴く」と「全員で聴く」を並べた。全員を聴くためにチェックを全員へ変える必要がなく、選択と予想点を保ったまま比べられる。
- 再生中・読み込み待ちのボタンは金の枠と停止の絵、`aria-pressed`で示す。同じボタンで止められ、終了すると再生の絵へ戻る。個別の候補のボタンも同じ動きにする。
- 選んだ人を聴いている間に人選を変えたら、古い再生と読み込み待ちを止める。全員を聴いている間は人選だけ変えられる。部の状態が変わった場合や、決定・変えずにもどるでは試聴を終える。
- 試聴の舞台にも、その演奏に座っていた部員を表示用に覚える。選んだ人の顔と実際の再生対象をそろえ、休みの区間でも席を保つ。
- 説明の吹き出しに「試聴は今の自由曲、予想は本番まで練習した目安」を追加。試聴の音・調子・採点・成長・保存形式は変更していない。A部門の予想は従来どおり課題曲4割・自由曲6割で、試聴は自由曲。

## 確認

本物のセーブを使わない確認画面で、実際のボタン・チェックを操作した。`browser-check.json`に38場面を保存した。

- 本人だけの指定が残った状態から、おすすめ31人を31人分の音で再生。別の本人の指定から候補一人を聴く場合も、その候補だけが鳴る。
- 選択31人→全員39人→選択31人を切り替え、チェック・67.3点の予想・部の状態・録音・オーディションの出来を保つ。全員の試聴中にチェックを変えても全員39人で続く。
- 選択を32人へ変えた時点で停止し、次回の試聴は32人になる。同じボタンや小さな再生バーでも停止でき、本人の短い演奏は自然終了で停止の印を消す。
- 読み込み待ちでの人選変更は予約を中止し、読み込み後も鳴らない。待機中に全員へ切り替えると全員だけが始まる。人選を決定した後も古い予約は始まらず、31人の出場が保存される。力と録音は変わらない。
- 5人の部で全員のチェックを外すと、決定と選択の試聴は無効になる。全員5人の音は、人選0人のまま比較用に聴ける。A部門でも人選・予想を保って選択30人と全員39人を比べられる。決定済みの人選から「変えずにもどる」でも部の状態を保ち、音を止める。
- 選んだ31人の舞台の顔・表示用の部員・実際の再生対象が一致する。
- 375×812のライト・ダーク、320×568で横はみ出しなし。試聴のボタンは44px以上。375×667で説明の吹き出しも画面内に表示。33本のスクリプトを取得し、起動と操作中のエラーなし。実際の録音音源を使った。

`check_audition_listen.js`は実際の再生・停止・人選の試聴関数と演奏データを使い、前の本人指定、選択と全員、本人の当日の一節、選び直し、待機中止、古い予約の無効化、自然終了、停止時の状態変更、0人と本番中の制限、保存内容の保持を確かめる。

全15曲の`check_audition_sound.js`で、本番と予想の採点と理由、A部門の4割・6割、保存内容の保持を確認。既存の個人録音の停止・現在の部員の試聴・停止後の演奏更新も通過。数式を変えていないため、新しい3年平均の調整はしていない。

字形チェックは既存の不足記号5字のみ。素材・フォントのダウンロードなし。画像は375×812。主な画面はPNG、舞台だけは画素を変えずにWebPへ変換し、どれも1枚200KB以内。
