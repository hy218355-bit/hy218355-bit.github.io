# 顔で選べるアンサンブル

- 人選を、顔・楽器・学年・G〜Sのランクを見比べられる2列のカードに変更。顔は既存の配役と原画を使い回す。カードは約65pxの高さで、長い名前も1行。
- 金の線とチェックは選択中のみ。8人を選ぶと未選択のカードを薄くし、追加できないことを読み上げでも伝える。選択した人は外せる。3人未満では決定できず、あと何人必要かだけ表示。
- 選び直すときは選択状態と決定ボタンだけ更新。一覧の作り直しによるスクロールとフォーカスの移動を防いだ。別のセーブで同じ年度を開いたときに、以前の選択を引き継がない。
- 決定ボタンはスマホの画面下に固定。再生中の小さなバーが出たら、その上へ避ける。別タブでは隠れる。
- 人選の長い説明と、演奏の凡例は「？」で開く吹き出しへ。元の文章を保持して常時表示を減らした。本番の吹き出しが舞台の裏に隠れないようにした。
- オーボエとクラリネットのアイコンを描き分け。同じ自作SVGパスをHTMLとcanvasで使用。全39席の16種類の線を初回だけ作って使い回す。
- 点数・成長・人選人数のルール・セーブ形式・顔の配役に変更なし。新しい素材やフォントのダウンロードなし。

## 確認

- `node tsukurikata/tools/check_faces.js`、`node tsukurikata/tools/check_stage_faces.js`、JavaScriptの構文と `git diff --check` が成功。
- `python3 tsukurikata/tools/check_glyphs.py`：既存の不足記号5字のみ。新しい不足なし。
- ブラウザ375px・ライト/ダークで4タブ・人選・合奏・本番を確認。横にはみ出さない。
- 人選は39人に顔と楽器があり、一覧の高さは1987pxから約1778pxへ。説明もたたんだので、最初の部員までの距離も短くなった。
- 解除・再選択・8人の上限・2人以下での決定禁止・Spaceでの選択を確認。最後の部員を選び直してもスクロール位置とフォーカスを維持。
- 決定ボタンの下端744pxに対し、下タブの上端751px。再生中は決定ボタン下端682px・小さな再生バー上端696pxで、重ならない。
- 本番の説明は、画面内の舞台より前に表示されることをDOMの実際の重なりでも確認。
- 4月から新年度まで49回の画面更新で進行し、2027年度へ移った。確認中のエラーなし。
- 開発用確認ページの初回読み込みで曲のスクリプトがそろわなかった際は再読み込みし、正常に起動してから上の操作を実行。製品に回避用の処理は追加していない。
