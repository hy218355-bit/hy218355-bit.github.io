# 部員カードの操作と今の力を先に見せる

- 顔の直下に本人・パートの試聴と席の移動を配置。今の四つの力はG〜Sのランクを横に並べ、本番の強さも同じ枠へまとめる。個人能力の数値は表示しない。
- 入部時の力との比較は「入部からの成長」で開く。従来の年月と四つの前後のランクは保持。同じ部員で音を切り替えても、開いている成長・譜読み・スキル・思い出は閉じない。移動先の未確定の選択は持ち越さない。
- 聴いている本人・パートのボタンを枠とaria-pressedで示す。記号の再生ボタンは既存SVGを直接使う。
- 録音のカードも聴くボタンと当時のランクを先に表示。名前と席の編集は出さない。保存形式・採点・成長・演奏は変更なし。素材とフォントの取得なし。

## 確認

375×812の両テーマで確認。今回の見本ではカード上端から試聴148px、席の移動203px。四つの力はC/B/C/Cのまま。成長を開いて本人→パート→全員に切り替えても開いたままで、保存内容が不変。席の移動と取り消しで元の状態へ一致。

入部時の記録がない旧セーブ、12文字の名前、昔の録音も確認。昔の録音は当時のA/A/A/Aを示し、試聴でも保存内容を変えない。横はみ出しと確認中のJavaScriptのエラーなし。録音カードの操作確認では楽器音源の読み込みが失敗し、既存の合成音への切り替えが発生した。音源の音質を確認したという結果には含めない。
