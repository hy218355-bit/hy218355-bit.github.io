# 席移動欄の横はみ出しを修正

部員カードの「席を移す」を開くと、長い選択肢の内容幅に引っ張られて選択欄がカードから出ていた。375pxの画面で横幅が400pxになり、カード内のほかの表示も横へ広がった。

`mc-move` を縮められるようにし、選択欄と決定ボタンを `minmax(0,1fr) auto` の2列に制限。選択欄を16pxの字・44pxの高さ、決定ボタンも44pxの高さにした。選択肢・名前・席の交代・能力変化・セーブの処理は変更なし。

375pxのライト・ダークで長い打楽器の選択肢を選んでも横幅375px。合奏側の選択欄207px、決定ボタン56×44px。部員一覧から開いても横はみ出しなし。実際の交代で、選んだ部員が打楽器へ、相手が元の席へ移ることも確認。確認用ページは本物のセーブと設定を書き換えない。

画像は375×812のPNG。字形チェックは既存の不足記号5字のみ。iPhoneへビルド・インストール・起動し、変更したHTMLが同梱内容と一致。
