# フルート・ピッコロの配役

これから作る入部候補のうち、フルート・ピッコロを希望する子と、自動配置でこの2楽器になる見込みの子を女子の名前と顔にそろえる。すでに女子の名前なら、その名前を保つ。他の楽器ではこれまでの名前生成を使う。

自動配置は従来の方法で先に計算し、新しく作った男子名だけを女子の名前候補から作り直す。重複は避け、同じidから同じ名前になる。顔は従来の`namePresentation`と`Faces`で表示する。新しい絵や保存項目は足さない。

席の選び方、希望する楽器、経験・才能・性格、能力の生成、やる気とまとまりは変えない。今いる部員、前のセーブの入部待ち、昔の録音の名前・顔・担当は変えない。手動での席替えも引き続きできる。

## 確認

- `check_flute_cast.js`：100種類の種で39人ずつ作り、フルート・ピッコロの女子配役、名前と顔の一致、名前の重複なし、再現性を確認。同じ入部候補の名前だけを変えても自動配置・入部後の能力・やる気・まとまりは同じ。今いる部員と入部待ちの子は変更なし。
- `check_faces.js`：100人の原画、以前の39人の配役、一般の名前生成、旧セーブの顔、容量と解像度、ランクの境界を確認。
- `check_recruits.js`：評判による経験者の割合、入部時の力、保存して再開したときの配役、前のセーブとの互換性を確認。
- 実際の`makeRecruits`と`autoAssign`から作った新入部員39人を375pxのライト・ダークで確認。ピッコロ1人・フルート3人は全員女子。名簿と部員カードで同じ顔を使い、表示の操作で部・録音は変わらない。
- 起動スクリプト33件を読み込み、横にはみ出さず、警告・エラーなし。字は従来の未収録5記号のみ。ファイルのダウンロードなし。
- iPhoneへRelease版を更新・起動し、変更ファイルの同梱ハッシュと実行中プロセスを確認。実機での画面操作は未確認。
