# 合奏の範囲を変えたら、選んだ区間から始める

修正前は、再生中に「中間部」を選んでも音は0〜81拍の全曲が鳴り続け、表示だけ中間部になった（`browser-check.json` の `before`）。

- 範囲変更時に再生と読み込み待ちを取り消す。曲の切り替えと同じく一度止め、次に合奏を押すと新しい区間から再生する。古い演奏のキャッシュを使わない。
- 現在の合奏にも、演奏するときの部員情報を一時的に対応づける。区間が休みでも顔を元の席に残す。録音と現在の演奏を区別し、通常の合奏は現在の部員カードを開く。
- 指揮の舞台も同じ現在の演奏から部員を表示する。演奏・採点・成長・保存形式は変えない。

## 確認

- 再生中の全曲から中間部へ変えると停止。選択欄も中間部のまま。再び合奏を押すと36〜58拍が鳴る。出番のない部員を含め39人の顔を表示。
- 読み込み待ちでも範囲変更で取り消し、読み込み完了後に勝手に古い範囲が鳴らない。押し直すと36〜58拍で再生。
- 通常の合奏のカードは編集可能。昔の録音は録音表示・範囲変更不可・録音用のカードのまま。
- 指揮画面にも39人の顔を表示。新年度まで49回進め、2027年へ到達。375pxの両テーマで横はみ出し・確認中のエラーなし。
- 操作前後で元の部と録音の保存内容が不変。顔の回帰確認に、現在の演奏と録音の区別・無音の部員の表示を追加。
- 構文と差分の空白を確認。字形の不足は既存の記号5字のみ。
- iPhone向けビルドとインストール成功。端末がロック中のため自動起動は未確認。最終のHTML・UI・指揮ファイルが同梱内容と一致。
