# 日本語・英語の切り替え

2026年11月3日。英語名はSchool Band Story。日誌の設定から切り替える。初期言語は端末の言語（日本語以外は英語）、選んだ言語は端末内の`suibu-language-v1`へ保存する。

## 表示と保存

- 日本語のゲームデータを共通の原稿として、表示する文字・読み上げ用の属性・canvasを翻訳する。入力値やボタンの処理用属性は翻訳しない。
- セーブ・録音・能力・成長・採点・音源へ項目や係数を追加しない。部員名は元の表記を保つ。録音・新入部員・卒業生の名前も照合から外す。
- 原文はDOMノードごとのWeakMapへ置き、言語を戻すと原文へ戻す。DOMの入れ替えを増やさず、入力や選択中のボタンを保つ。
- 連結した日誌は、かっこ・引用符の対応、数値の単位、文章のまとまりを確かめて翻訳する。助詞だけの曖昧な一致は使わない。
- 英語の本文は端末標準フォント、手書きの部分は端末にあるGeorgiaを使う。フォント・辞書を外部から読まない。既存の動きを減らす設定と演出の設定を保つ。
- iOSのホーム画面名は日本語「吹奏楽部」、英語「School Band」。承認済みのアイコンは共通。

## 原稿の作り方

`source-strings.json`の番号に`en-01.json`〜`en-12.json`が対応する。番号を振り直さない。補足は`extra.json`。`extract.py`は初回の収集用で、正規表現やコードの断片も含むため、そのまま製品のコードを書き換えるためには使わない。

```
python3 design/english/build.py
node design/english/check-text.js
```

`build.py`は辞書とランタイムを`tsukurikata/js/i18n-en.js`・`i18n.js`へ生成する。変数の参照が原文と合わない場合は止める。

`check-text.js`は数値・日付・曲名・名前・楽器・canvasの呼び出し・日本語への復帰を検証する。実際にゲームを進めた部の既存の日誌160件について、名前を除いた日本語の取り残しが0件であることも確認する。収集原稿の短い汎用断片は実際の文脈を持たないので、単独の翻訳成功率を製品の完成率と扱わない。

## 画面の確認

- `qa.html`は製品HTMLと同じスクリプトを読み、保存先をメモリへ分けるブラウザ用確認版。実際のセーブは読まない。`?theme=light`・`?theme=dark`で見る。
- ブラウザ375pxで、日誌の日本語→英語→日本語、フォーカス、カード、改名の中止、席選びの選択・解除・中止を確認。解除すると移動ボタンが無効になる。
- `capture.py`・`capture.js`はビルド済みアプリのコピーへ確認用selftestを入れ、専用シミュレータだけで撮影する。製品のselftestや実機のセーブは変更しない。同梱195ファイルをソースと照合してから撮影する。
- 状態は`../app-store/fixture.json`を使用する。相談・本番・卒業式は製品の進行関数で進め、能力を撮影用に上書きしない。言語を往復する前後の`S`とゲーム用保存キーが同一か確かめる。
- 375pxで今週・合奏・名簿・カード・日誌・相談・指揮・結果・卒業式をライトとダークで確認。初期画面と発表も撮影。横幅・壊れた画像・翻訳の取り残し・エラーを記録する。実機のミラーリングは使わない。
- `checks.json`に最新の各撮影結果、`screenshots/`に画像と生ログを置く。シミュレータの所要時間は実機の速さを保証する計測ではない。
- 日本語の新しい設定文字は同梱3ウェイトすべてにあることを確認。`check_glyphs.py`は翻訳辞書中の法律文書・欧文・コードの範囲指定も拾う。英語は端末標準フォント、法律文書は既存の標準フォントで表示し、その検出だけを理由にフォントを取得し直さない。

## 掲載素材

`store-en.json`は英語名・副題・紹介文・説明・キーワードと地域別の紹介の切り口。文字数制限内で、初回の無料・広告なし・課金なしに合わせてある。`iphone-store-*`は1206×2622、`ipad-store-*`は2064×2752。画像は実際のアプリを撮影し、アルファチャンネルだけ外したもの。見た目や能力を画像加工で作り足さない。

日本を先行し、英語版の確認後に米国・シンガポール・豪州を試す準備。現在のApp Store Connect設定は日本のみ。英語のストア原稿・画像の登録、海外への配信設定、公開は未実施。地域別の売上予測や追加の解析SDKは含めない。
