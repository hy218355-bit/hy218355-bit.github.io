# 席を選ぶ間の操作を整理

375pxの合奏画面で席を選ぶと、下の「いまの音で合奏／指揮する」がカード内の「移す」に重なり、確定する場所を見失いやすかった。楽器の切り替えも、開くまで9種類のアイコンが見えなかった。

## 変えたところ

- 楽器の9種類を最初から3列のアイコンで表示。楽器名・顔・席・選択の金枠とチェックはこれまでどおり。
- スマホの席選び中は「やめる／移す」をタブの上に固定。合奏から開いたときだけ合奏・指揮ボタンと入れ替える。閉じたり別のタブへ移ったりしたあとも、必要なボタンが戻る。
- 合奏を聴きながら席を選ぶと、移動バーに停止ボタンを残す。部員一覧では既存の小さな再生バーを使い、停止を二つ出さず、移動バーをその10px上へ置く。
- 「やめる」とEscapeは選択を消して閉じ、カードの先頭へ戻す。席・能力・日誌・セーブは変えない。確定前の二人の顔とランク、移動後に元へ戻す処理は残す。

## 確認

`browser-check.json`に実際のボタン操作と位置・状態を保存。確認ページは本物のセーブや設定を書き換えない。

- 375×812のライト・ダークで、楽器一覧・二人の移動前後・部員一覧で再生中の表示を確認。スクリーンショットはPNG、1枚200KB以内。
- 選択前後で固定バーの位置は変わらず、確定は高さ44px。横はみ出しなし。320×568・375×667・768×1024でも確定ボタンの中心で実際にボタンが当たり、1280pxではカード内の通常配置。
- 再タップで解除、楽器変更で未選択、中止後の再開も未選択。本番中は選んでも確定不可。選ぶだけ・中止では部の状態が一致。
- 実際の移動後の全員の席・ランク・顔が予告と一致。直後の「元に戻す」で部の状態も一致。
- 合奏中は移動バーから停止でき、席選びは開いたまま。読み込み待ちも止められ、後から読み込みが終わっても勝手に再生しない。
- 部員一覧の再生バーとの間は10px。日誌では移動バーは隠れ、合奏へ戻ると合奏の操作が出る。編集欄を開いたまま部員カードを閉じても、合奏ボタンを隠さない。
- 既存の席取り消し・改名・演奏更新・停止後の表示・音源再試行の確認を実行。字形チェックは既存の不足記号5字だけ。フォントのダウンロードなし。前回の日本語コメントにあった字を言い換え、コメントを含めたチェックにも新しい不足字を残さない。

ゲームの点数・伸び方・席移動時の能力変化・セーブ形式・顔の配役は変更していない。
