# 顔を見ながら、合奏を聴く

- 合奏・停止・指揮を画面下のタブの上へ。スクロール中も操作できる。48px以上のボタンを2列に並べ、既存の自作SVGの再生・停止・保存と、新しい指揮棒を使う。
- 舞台から開く部員カードを、舞台と力の色の説明のすぐ下へ移した。名前を変える・本人やパートだけ聴く・成長を見る操作はそのまま。閉じたら舞台へ戻る。名簿から開いた場合の戻り方もそのまま。
- 録音・聴き方・音の動きを48px以上の見出しで開く形にした。会場、範囲、聴くパートは見出しにも表示する。プルダウンは16pxの字と44px以上の高さ。
- 録音の選択は部員を開いても保つ。録音がない場合には選択・再生・保存を無効にする。
- 音の動きは開いたときに幅を測り直して描く。閉じている間は再生中も描かない。部員のパートを名簿側から選んだときには、自動で開いて表示する。
- 読み込み中も停止ボタンを表示する。取り消したら元の表示へ戻り、読み込み完了後も勝手に鳴らない。
- 舞台の説明を、現在の顔と楽器の表示に合わせた。「内側の輪は1年生」という古い説明を外した。
- 演奏・採点・成長・セーブ形式・舞台の配置とタップ範囲・顔の配役は変更なし。素材・フォントのダウンロードなし。

## 確認

- 375pxのライト・ダークで合奏と部員カードを確認。4タブも両テーマで横幅375pxに収まる。
- 舞台の本人を押すとカードが舞台のすぐ下に出る。カード上端は約14px。閉じると舞台へ戻る。
- 古い録音を選んでから部員を開いても録音の選択を保ち、その録音の名前で再生できる。再生中は合奏から停止へ切り替わり、止めると合奏に戻る。
- 会場・範囲・聴くパートが見出しにも反映。音の動きを開くとその幅で描く。
- 読み込み中の状態を確認ページだけで作り、停止したあとで読み込みを完了させても再生しないことを確認。
- 録音がないときには録音の選択・聴く・保存が無効になる。
- A部門の課題曲へ切り替えられ、部員の力と週を変えない。指揮ボタンから指揮の画面を開ける。
- 4月から新年度まで49回の画面更新で2027年度へ進み、確認中のエラーなし。日誌の全文も保持。
- JavaScriptの構文、顔・舞台・名前の既存チェック、`git diff --check` が成功。字のチェックは既存の不足記号5字のみ。
- iPhoneへのビルド・インストール・起動が成功。変更した実行ファイルと出典の4ファイルは同梱内容と一致。実機の見た目はオーナーが確認する。
