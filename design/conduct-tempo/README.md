# 拍の音符とテンポ表示をそろえる

375pxで確認した修正前のテンポ欄は、4連続を出しても横にはみ出していなかった（`before.json`）。その幅を保ちながら、曲によって長い拍名と汎用の音符が混在していた表示を、曲の1拍に合う小さな音符へそろえた。

## 変更

- `uiBeatIcon`で、2分音符・4分音符・8分音符・付点4分音符を自作SVGで描く。2分音符は白抜き、8分音符は旗、付点音符は点を付ける。色は`currentColor`。図形は初めに作り、毎フレーム作り直さない。
- 現在・指定・連続数を同じ行で読める配置にする。現在と指定は44px以上の高さで押せ、音符と数字の意味がTIPSで開く。押す操作を指揮のタップに数えない。
- 読み上げでは「いまのテンポ／指定」と拍名・数値がそろうようにする。平均テンポも同じ音符で表示し、記録に残す数値と単位は変えない。
- 新しい素材・フォントの取得なし。SVGの出典は`tsukurikata/img/CREDITS.md`に記載。演奏の速さ・拍の長さ・判定・採点・セーブの形式は変更しない。

## 確認

- 375×812のライトとダークで4種類の音符を確認。実際の曲は威風堂々（4分音符）、歓喜の歌（2分音符）、新世界より（8分音符）、ワルキューレの騎行（付点4分音符）。白抜き・旗・点が正しく残り、汎用アイコンへ変わらない。
- 375×667のダークでも2分音符と付点音符を確認。テンポ欄・指定・4連続が横に収まり、下端も画面内。現在と指定の操作面は高さ44px。
- キーボードでテンポの説明を開いても、最初のタップは0回のまま。Escapeは説明だけを閉じ、テンポ出しへ戻る。実際の3回のテンポ出しと4回の入力は全て「ぴったり」。
- 自然終了で録音1件が残り、結果の平均テンポも付点4分音符で表示。部員と演奏前の録音はタップ中に変わらない。41音源から`SampleVoice`で演奏する。
- 起動33/33、コンソール警告・エラーなし。`check_conduct_cue.js`と`check_conduct_timing.js`で予告・入力時刻・保存した指揮の回帰確認を実行。全15曲の区間とテンポ変化の確認は予告の処理に対するもので、今回の音符表示は上記の4種類で確認した。
- `check_glyphs.py`は以前からの未収録5記号のみ。新しい不足なし。
- Release版をiPhoneへ導入し起動。ミラーリングなしで実行プロセスと4ファイルの同梱ハッシュを確認。実機の画面・音・操作感はオーナー側で確認する。

`browser-check.json`・`console-check.json`・`iphone-check.json`・PNGへ記録。`notes.html`はゲームと同じSVGを並べた形の確認用。確認ページはセーブを書き換えない。
