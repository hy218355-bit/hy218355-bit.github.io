# テンポ出しを中断したら、数え直せるようにする

演奏前に2回だけタップして手を止めると、「あと2回」と古い入力が残り続けていた（実画面の`before.json`）。予告は進み続けるため、再び振り始めても前の回数と長い間隔の続きとして扱われる。

## 変更

- 最後に振ってから4拍を超えて止まったら、開始前のカウントだけを消す。最初の案内へ戻り、下の聞こえた拍の枠も消す。予告は元の区間の開始拍から数え直す。
- 再開した新しい入力だけでテンポを決める。`cdCountPeriod`を予告・中断の長さ・開始テンポで共用し、従来の中央値と0.3〜1.6秒の範囲を保つ。
- 描画が止まっていた場合も、次の入力で中断を確認する。古い処理待ちの入力・複数指・二度押しの扱いは維持する。
- 演奏が始まってからは数え直さない。手を休めても部員は最後のテンポで吹き続ける。判定幅・指揮の効き・点数・伸び・録音やセーブの形式は変更しない。
- 既存の案内を再利用し、画面の文章や操作を増やさない。素材・フォントの取得なし。

## 確認

- 変更前は「4拍を超えた中断で数え直す」の回帰確認が失敗（`before-test.txt`）。変更後は境界の4拍まで続けられ、4拍を超えると待ち直す。2・3・4・8拍子、1入力だけの中断、描画なしの再入力、演出ふつう・短く・なしを確認。
- ブラウザの375pxライトで「春」の4拍目からテンポ出し。2回入力して止めると0回へ戻り、案内・予告・拍の枠も戻る。フォーカスはタップ面に残り、部員と録音は変化しない。
- 新しく振った4回で演奏開始。続く4入力はすべて「ぴったり」。実音は`SampleVoice`で鳴る。演奏中の4拍の休止ではカウントを消さず、自然終了で録音1件が残り、部員の情報は保持される。
- ダーク・演出なしの「威風堂々」でも、中断後は0回へ戻り、新しい4入力で演奏を開始。375pxで横幅375px、操作面とテンポ欄が画面内に収まる。両テーマをPNGへ保存。
- 全15曲の区間・予告・判定、入力待ちの補正と保存した指揮は回帰確認済み（`cue-check.txt`・`timing-check.txt`）。起動33/33、エラーなし（`browser-check.json`・`console-check.json`）。
- 字の確認は既存の未収録5記号のみで、新しい不足なし（`glyph-check.txt`）。製品の文章は追加していない。
- Release版をミラーリングなしでiPhoneへ導入。同梱したHTML・指揮コードは一致（`iphone-check.json`）。端末がロック中のため起動できず、実行プロセスも未確認。実機の見え方・音・操作感と起動は、あとでオーナーが確認する。

確認ページはセーブを書き換えない。ブランチ`codex/design`、pushなし。
