# 聴き方を変えても、入力中の名前を保つ

「聴き方」の聴くパートを変えると、カード全体が作り直され、名前の未保存の入力が消えていた。変更前はボタンの識別番号も1・2・3から4・5・6へ変わった。`before.json`に記録。

対象の変更では、音の指定と現在・録音の試聴の印だけを更新する。カードを描き直さず、名前の入力、成長・思い出の開閉、同じボタンと再生位置を保つ。部員の顔・能力・成長・採点・音・録音・セーブ形式・表示する文言は変えていない。新しい画像・フォント・演出・外部取得もない。

実ブラウザ14状態で、停止中・再生中・読み込み待ちの対象変更を確認。本人1人・パート4人・全員39人の実際の音が選択と一致し、同じ再生を維持した。入力中の名前、開いた成長・思い出、ボタンの識別番号、部と録音のハッシュも保持。待機中に全員を選んで解放すると全員で再生する。録音時の本人とカードのボタンも保ち、本人を選んだときだけ印が付く。

375pxのライト・ダーク、44px以上の試聴操作、横にはみ出さないことを確認。49操作で2027年度へ進み、4タブは375pxに収まる。33スクリプト起動成功、コンソール警告・エラーなし。本人の試聴と録音カードの全15曲の既存検証も合格。検証ログと実画面のスクリーンショットを同じフォルダに保存した。QAは本物のセーブと設定を書き換えない。

iPhoneへのビルド・導入・起動コマンドに成功。同梱のHTMLとUIのSHA256が作業ツリーと一致。実機の画面・音・操作感はオーナー側で確認する。ミラーリングは使っていない。

`codex/design`、pushなし。
