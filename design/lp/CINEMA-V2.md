# ②「放課後の音楽室」の改善版

オーナーの「2がいいけど、もっと良くできる」に対応した、LPだけの改善。元の5案とゲーム本体は残す。顔の描き方やゲーム全体のデザインを承認済みとは扱わない。

## 開く

`http://127.0.0.1:8001/design/lp/cinema-v2.html`

停止している場合は、worktreeのルートで `python3 -m http.server 8001 --bind 127.0.0.1` を起動する。

## 変えたところ

- **主役の絵**：単純な窓・椅子のSVGから、原画を新しく制作。放課後の光、ホルン、譜面、楽器ケースで、吹奏楽部の気配が伝わるようにした。人物・顔は入れない。
- **最初の画面**：「あの音楽室を、もう一度。」を継続。本文を2行に絞り、顧問になるゲームだと見出しの前で伝える。入口のボタンと、説明へ進む導線を整理。
- **ページの流れ**：音楽室 → 練習を選ぶ → 合奏の音 → 入部から卒業、の順。暗い場面と明るい紙面を交互にし、同じ調子が続かないようにした。
- **具体的な遊び方**：触れる練習方針と、注目するパートを切り替えられる舞台の見本を追加。ゲーム処理は呼び出さない。音の再生はしない。
- **スマホ**：375pxで文字・ボタン・横幅を確認。画像の切り取りを変え、ホルンの中央まで見せる。練習行の名前とランクは1行。
- **文字・色**：同梱のZen Kaku Gothic New 400／700とShare Tech Monoを参照。夜の紺、自然な紙色、光の金に絞る。新規フォントのダウンロードなし。

## 原画

組み込みimage_genで本提案用のオリジナル画像を生成し、`assets/after-school-v2.webp` に保存。1600×900、162,344 bytes。外部素材のダウンロードなし。元の生成原稿はCodexの生成画像フォルダに残した。最終プロンプトと原稿の場所は `assets/after-school-v2.prompt.txt`。

## 確認

- PCと375pxのブラウザで全体を確認。
- 375pxの `scrollWidth=375`、原画は読み込み済み。
- 方針「基礎を固める」で見本の予定が「基礎練習」へ変わる。
- パート「ホルン」で対象の点だけが強調される。
- ブラウザの警告・エラーなし。
- `node --check design/lp/cinema-v2.js` と `git diff --check` を実行。
- 動きは追加せず、`prefers-reduced-motion` ではページ内のスクロールも即時にする。
- ゲーム本体とiOSアプリは変更しない。push・公開なし。
