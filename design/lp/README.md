# LPデザイン5案

オーナーの「まずLPデザイン5個」の依頼に対する、ゲーム紹介ページの独立モック。ゲーム本体・顔の描画・アプリアイコンの採用は未承認のまま。公開・pushはしない。

## 見る

worktreeのルートで `python3 -m http.server 8001 --bind 127.0.0.1` を起動し、`http://127.0.0.1:8001/design/lp/` を開く。一覧の各案から、下までスクロールできるLPへ移る。

| 案 | 見せたいこと | 構図 |
| --- | --- | --- |
| 01 FRESH PLAY | 軽快に、触って遊びたくなる | 白とライム。短いコピーと傾けた端末。練習画面を主役にする |
| 02 AFTER SCHOOL | 音楽室の空気と、部員と過ごす時間 | 放課後の光。画面いっぱいの環境の絵、静かな余白 |
| 03 CLUB POSTER | 音楽と部活の楽しさ、高揚感 | 大きな文字、ラベンダーとピンク、楽器とチケットのコラージュ |
| 04 SOUND LAB | 練習で音が変わる、このゲームの面白さ | 深い黒とライム。座席と波形を大きく見せる |
| 05 SMALL STEPS | 初心者の部員が育つ、毎週の楽しみ | 白とコーラル。成長の記録と、明るく軽い編集ページ |

選択用の案であり、特定の絵柄や方向はまだ採用しない。顔は入れていない。

## ファイル

- `index.html` / `lp.css` / `lp.js`：依存パッケージなしのHTMLモック。`?v=1`〜`?v=5`で各案を表示。
- `screenshots/01-desktop.png`〜`05-desktop.png`：1280px幅の全ページ撮影から、先頭900pxを比較用に切り出したPNG。
- `screenshots/01-mobile.png`〜`05-mobile.png`：375×812のスマホ画像。
- `screenshots/*-full.jpg`：スクロールするページ全体の撮影原稿。
- `screenshots/viewport-checks.json`：375pxでの幅の確認。
- `export_previews.py`：撮影原稿からPNGを作成する道具。

## 素材と範囲

Sitesスキルの紹介用サイトの設計手順を、ローカルだけで使用。登録・デプロイ・外部へのアップロードは行わない。

放課後の音楽室・楽器・音符・座席・波形・画面イメージ・ロゴはすべて自作のSVG／HTML／CSS。写真・外部素材なし。フォントは既存のZen Kaku Gothic New 400／700とOSの書体を使用し、新規ダウンロードなし。著作権の出典は親フォルダの `CREDITS.md` も参照。

ゲーム内の事実は既存のAGENTS.mdとゲームに基づく。画面・波形・成長記録は「イメージ」として表示。実演や実績の証拠を装わない。CTAはローカルの変更していないゲームへ別タブで移動し、ページ内の案内は対応する説明へ移動する。音は自動再生しない。

5案とも375pxで `scrollWidth=375`。ブラウザで全案の表示を確認し、警告・エラーなし。見出しの不自然な折り返しとロゴの配色を修正済み。動きは使わず、ページ内スクロールは `prefers-reduced-motion` に合わせる。

採用する方向のOKを受けるまで、ゲーム本体のファイルを変更しない。
