# 行事に行く部員を、顔で選ぶ

## 変更

- 名前だけの札を、顔・名前・学年・選択のチェックがある2列のカードへ変更。楽器ごとにまとめ、特に伸びる子の星は顔に重ねず端へ添える。
- 選ぶ間はその場の枠とチェックだけを変える。選択上限では未選択の子だけを無効にし、選んだ子は再タップで解除できる。人数上限と対象者は従来と同じ。
- 1人以上を選ぶと、画面下に顔と人数、確定・中止を表示。この間は通常の週送りと入れ替え、再生中の小さなバーやタブバーと重ねない。
- 行事の詳しい対象と、選ばなかった場合の説明はTIPSへ移した。ほかの部員の開閉は保ち、特に伸びる子がいない行事では最初から全員を見せる。
- 確定後は参加した子の顔と結果を表示し、結果へ移動。変わったことは開いて見られる。同じ行事を描き直しても顔と開閉を保つ。
- 顔の参加者情報はUIの一時的な写しだけ。前の結果が名前だけの場合は、今の名前か元の名前で一人に決まるときだけ顔を付ける。同名や区切り記号を含む名前は推測しない。
- 小さい画面で行事の選択と再生バーが重なっても、個別練習のメニューを操作できる高さに制限する。

点数・成長・行事の効果・音・保存形式は変更なし。従来のresolveOutingへ同じ順番のidを渡す。新しい素材・フォントの取得なし。

## 確認

最終確認ページはqa-outing-faces-6。製品と同じスクリプトを使い、確認ページだけ保存を止めた。

- browser-check.jsonに43場面、4タブ×両テーマをtabs-check.jsonへ記録。読み込み33/33、エラーなし。375pxで横のはみ出しなし。
- 1・3・4人の上限、解除、他の部員からの選択、上限0と1人だけ、席のない部員の除外、コンクールの控えを含める条件を確認。
- 選択・中止では部の状態は不変。確定後の全員のデータ・結果・行事の日誌・顧問の経験が、同じidを従来の処理へ渡した予測と一致した。
- キーボードの選択で本人のフォーカスを保つ。TIPSのEscapeは説明だけを閉じる。中止は閉じた一覧内の見えないボタンを避け、表示中の候補へ戻す。
- 確定した3人の顔とidが一致。前の結果の名前が一意なら顔を表示し、同名と区切りを含む前の名前では表示しない。今回選んだ区切りを含む名前は正しいidで顔を表示。
- 320×568の長い名前、4人選択、再生中のバーを確認。小さい画面で個別練習メニューが固定ボタンと重なる問題も修正し、休むまで実際に選べた。
- 初年度を実際の69操作で2026年4月から2027年4月まで進行。行事の対象を10場面、実際の参加者と結果の顔を5回照合。コンソールの警告・エラー0件。
- 既存の顔100人・舞台の顔と楽器・本人の録音停止・卒業の保存と移動の確認が成功。構文・差分チェック成功。字形チェックは既存の不足記号5字のみ。

PNGは通常375×812、小さい画面は320×568。全て1枚200KB以内。小さい練習メニューの修正前後の寸法はbrowser-check.json、年度の操作はyear-flow.json、コンソールはconsole-check.jsonに保存した。
