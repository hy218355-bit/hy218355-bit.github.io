# 説明を閉じても、選びかけの練習を残す

練習メニューを開いてからランクの説明を開き、Escapeを押すと、説明とメニューが一緒に閉じていた。`before.json`は実ブラウザで観測した開閉状態。

今週のキー操作は説明を先に閉じる。次のEscapeで練習メニューを閉じ、元の本人・パートの操作へ戻す。疲れた部員の顔から来た場合も戻り先を保つ。本番準備も説明を先に閉じる。長押しと文字の変換中では次の選択まで閉じない。

画面の文言・色・素材・音・練習内容・成長・点数・セーブ形式は変えていない。追加のダウンロード・アニメーションはない。

## 確認

- `check_week_escape.js`：製品のイベント処理を使い、練習・行事・本番準備の18通りを確認。説明、長押し、変換中、別のキー、対象外の場所を区別し、一度の入力で一つだけ閉じる。
- 実ブラウザ11状態：個人・パート・疲れた顔からの練習で、最初のEscapeは説明だけを閉じ、8個の練習と戻り先を保つ。次のEscapeで元の操作へ戻る。本番準備の説明と準備欄も二段階で閉じる。各操作で部のハッシュが変わらない。
- 375pxのライト・ダーク、練習の選択64px以上、横にはみ出さないことを確認。49操作で2027年度へ。33スクリプト起動成功、4タブ375px、コンソール警告・エラーなし。
- 字の検査は以前からある記号とコメントの8字を報告。表示する文字は増やしていない。

QAは本物のセーブと設定を変えない。実際の状態は`browser-check.json`、照合は`browser-assertions.txt`、実画面は`screenshots/`。

iPhoneのビルド・導入・起動コマンドに成功し、同梱HTML・UIと作業ツリーのSHA256一致を確認。実機の見た目・音・操作感はオーナー側で確認する。ミラーリングは使っていない。
