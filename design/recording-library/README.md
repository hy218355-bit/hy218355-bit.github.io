# 録音を、顔と曲で選ぶ

録音の長いプルダウンを、年度ごとのカードに置き換えた。曲・会場・録音時の部員の顔を見て、その行を一度押すと聴ける。再生中の行は金の枠と停止の印になり、もう一度押すと止まる。保存は右端の44pxのボタンから行う。

録音中は画面下に「いまの音」を出し、現在の部員の合奏へ直接切り替えられる。一覧は高さを制限し、何年続けても操作を下へ押し流さない。開き直したときは、再生中または最後に選んだ録音へ戻る。

## 変えたところ

- `ui.js`：録音一覧と切り替え。録音のidは演奏の外のWeakMapに覚え、同じ題名でも取り違えない。別の録音を選ぶと、前の個人試聴とカードを閉じ、全員の音で聴く。
- `conduct.js`：録音と演奏の一時的な対応。本番・指揮の開閉に合わせて一覧の操作を止める。
- `index.html`：年度見出し、録音カード、保存ボタン、現在の合奏へのボタン。
- `check_audition_listen.js`：音の確認だけを行う環境に、画面更新関数の空の代役を補った。製品の処理や確認項目は弱めていない。

採点・成長・セーブ・録音の音・書き出しの処理は変えていない。顔は録音に保存済みの部員から表示する。絵やフォントの追加・ダウンロードはない。

## 確認

- 375pxの4タブ×ライト・ダークで横はみ出しなし。再生と部の状態を保持。
- 同名・同曲の別の録音をidで切り替え、1行だけに再生の印が付く。再タップ・自然終了・待機の中止で印を解除。
- 読み込み待ちで録音を切り替え、中止後に読み込みが終わっても鳴らない。「いまの音」へ切り替えた後は現在の演奏だけが鳴る。
- 録音の演奏全体のハッシュが、従来の作り方で作った演奏と一致。現在の合奏も現在の部から作った演奏と一致。表示と再生の操作で部の状態・録音・能力は不変。
- 改名・席替え後も、過去の録音の舞台から開くカードは当時の名前・学年・席・G〜Sを表示。現在の名簿の同じ席にいる別人と取り違えず、改名・席替えの操作も出さない。
- 書き出す録音と聴く録音を別々に選べる。非同期の書き出し完了後は保存ボタンへフォーカスを戻し、途中でほかの行を操作した場合は奪わない。この確認ではQA専用の代役で書き出し先を記録し、実際のWAV保存・共有は実行していない。
- 0件・1件・68件と長い題名を確認。68件は配置確認用の合成一覧。最古の2023年度までスクロールして聴ける。320×568pxでも横はみ出しなし、保存ボタン44px。
- 本番と指揮の表示中は一覧の再生・保存を無効化し、閉じると元へ戻る。
- 実際の画面操作69回で4月から新年度へ。録音は9件に増え、画面エラーなし。33スクリプトすべて読込成功、コンソールの警告・エラーなし。
- 個人録音の中止、現在の本人の試聴、最新状態の合奏、人選の試聴、週送り後の停止の5つのNode確認が成功。構文確認成功。字形は既存の不足記号5字だけ。
- iPhone用署名付きReleaseビルド成功。変更した3ファイルが同梱内容とSHA-256で一致。実機iPhone 17は接続状態がunavailableのため、今回はインストール・実機表示を未確認。

開くときのスクロールは演出の設定と`prefers-reduced-motion`に合わせる。画面確認ページは演出なし、本物のセーブと設定を書き換えない。
