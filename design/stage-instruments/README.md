# 演奏の楽器とアンサンブルの人選

- 顔を約2割小さくし、楽器の輪郭を18pxで添えた。全39席を15種類の自作SVGパスで描く。楽器ごとの線は初回のみ読み、毎フレーム使い回す。
- 小さくなった顔と楽器を含めてタップできるようにし、楽器決めの元の座標は維持。
- アンサンブルは、選択中だけ金の線・色・チェック。解除後はタップ中のhoverが残っても通常の線。44px以上の高さと、キーボード用のフォーカス表示を確保。
- 点数・成長・人選ルール・セーブ・顔の配役は変更なし。

## 確認

- `node tsukurikata/tools/check_stage_faces.js`：240/309/343/720pxで顔と楽器が外へ出ず、どちらを押しても同じ席。全楽器のパスを一度だけ作る。顔100人のキャッシュも維持。
- `node tsukurikata/tools/check_faces.js`：100人の顔・元の39人・名前との対応・旧セーブ・画像容量。
- `python3 tsukurikata/tools/check_glyphs.py`：前からの不足記号5字のみ。新しい不足文字なし。
- ブラウザ375pxで合奏・本番をライト/ダークで確認。実際の合奏の再生と停止、ピッコロの絵を押して本人の部員カードが開くことを確認。
- 人選は両テーマで5人から4人へ解除、再選択で5人へ。`aria-pressed` と線・チェック・人数が一致。横はみ出しなし。詳細は `screenshots/checks.json`。
- 開発用ブラウザ初回のスクリプト読み込み不全は、確認ページのURLに識別子を付けて再読み込みし解消。製品に回避用の処理は追加していない。

実機のビルド・同梱ファイルの照合結果は `iphone-build.json`。実機の見た目の確認はオーナーが行う。
