# 出場者全員が、当日の顔で舞台に立つ

## 見つかった不一致

「白鳥の湖」の県大会で、録音の出場者は34人なのに、舞台の顔は31人だった。その曲に音符がないトランペット2人と打楽器1人が消えていた。`before.json`と修正前の画像に記録。

本番を聴く経路は`perform(recCtx(rec))`だけを渡し、表示する本人の情報を添えていなかった。`CD.who`も音符のある人だけだった。カードは今の名簿を見ていたため、アンサンブルでは本番後に伸びた力が、その本番の演奏中に表示されていた。

## 変更

- `stagePerformance`で音の入力は保ち、`rec.snap.members`を表示用のWeakMapへ添える。現在の本番として扱い、録音一覧の再生中とは混ぜない。
- `cdSetMembers`で出場者全員の`CD.who`と、曲の中で音符がある`CD.sounding`を分ける。休む部員も当日の席に残す。
- 舞台の選択とカードは`cdMemberById`で当日の本人を取得。名前・学年・楽器・G〜Sの力・本番の強さを今の名簿へ置き換えない。
- 曲を休む本人にも顔とカードがあり、「この曲は休み」と一言で示す。本人だけの試聴は出さず、ほかの子の音を聴いてから休む子へ移れば全員の音へ戻す。
- ひとことの譜読みも、その演奏の曲と当日の記録を使う。課題曲のことを自由曲と呼ばず、選曲前にも落ちない。
- A部門の課題曲・自由曲、課題曲から自由曲の指揮、通常の指揮、アンサンブルへ同じ扱いを適用。
- 入場の`who`を`drawStage`でも確かめる。以前は当日の部員マップを使うと`who`を無視していたため、空の舞台や入場途中にも全員が見えていた。当日の席順で空→入場途中→全員へ進み、そろってから演奏を始める。演出の設定と既存の待ち時間は保つ。

採点・成長・音符・音源・録音内容・セーブの形は変更していない。部員の情報は表示用だけ。素材・フォントの取得なし。

## 確認

- 375×812のライト・ダークで実際の県大会を再生。34人全員の顔と、その曲を休む岩崎結衣のカードを確認。音は`SampleVoice`で鳴る。横幅375px内。
- カードの名前・学年・席・ランクは当日の記録と一致。休む子に試聴ボタンを出さない。鳴る本人だけの音、そこから休む子へ移ると全員の音へ戻ることを確認。
- Escapeでカードだけを閉じても本番は継続し、結果は未発表のまま。これらの操作で部と録音が不変。
- アンサンブルの実際の本番では、当日の音程F・音色E・本番の強さFを表示。本番後の名簿はそれぞれE・D・Eへ育つ確認用データでも、先に成長後のランクを出さない。
- 375×667の指揮では39人が舞台におり、その曲を鳴らす34人と区別する。
- 演出ふつうの実画面は、空の舞台から2人ずつ34人まで入場し、その後に再生開始。人数の履歴は`watchCast.entrance`に保存。短く・なしでは既存の分岐を使い、入場を追加しない。
- 49操作で2027年度へ進行。起動33/33、コンソール警告・エラーなし。
- `browser-check.json`は各操作直後に保存。`browser-assertions.txt`で出場者・当日の情報・音のハッシュ・操作後の状態を照合。
- `node tsukurikata/tools/check_stage_cast.js`：全15曲で音と保存が不変。音符のない延べ19人も含めて全出場者を表示。少人数、改名・席替え・卒業後、当日の譜読み、A部門の2曲と指揮への切り替え、アンサンブルの開始、現在の名簿にいない人の入場も確認。
- 舞台の顔・席のタップ・画像の再利用、指揮の予告と入力時刻、全15曲45編成のアンサンブル試聴も既存の検証に合格。各`*-check.txt`を保存。
- 字の検査は既存の5記号（▶♩♮⤓𝄪）とコードコメントの「常」が不足。今回追加した表示文言は本文3ウェイトと手書きのKlee One 600の全字を別に照合し、収録済み。前回の待機改善の説明もこの区別に訂正した。
