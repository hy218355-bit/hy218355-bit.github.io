# 朝野先生と、はじめの部活

新しく始める部に、楽器 → 選曲 → 1週間の練習 → 合奏の4段階を案内する。
説明を読み進めるだけでなく、いつもの顔・選曲・練習・再生の操作へ移る。
案内が配置や曲を決めたり、週を進めたりすることはない。

- スキップでき、日誌の「朝野先生のはじめての案内」から再開できる。
- 途中のセーブでは自動表示しない。日誌から開くと今の部を保った説明になる。
- 現在の部の音が実際に鳴ったときに合奏を達成とする。お手本・無音・読み込み待ちでは達成しない。
- 本番と結果では通常の先生の助言を表示し、最初の歓迎演奏を終えたら案内を終える。
- 進み具合は端末の `suibu-onboarding-v1` だけに保存する。ゲームのセーブ・部員・録音・採点・成長は変更しない。
- 画像は採用済みの `advisor-asano.webp` を使い回す。新しい絵・フォント・外部取得はない。
- 案内にアニメーションは足さず、移動は静止で行う。
