# 録音中の曲名・範囲・会場をそろえる

《新世界より》第2楽章の前半を録音から再生しても、曲名は現在の「天国と地獄」、範囲は練習中の「中間部」が残っていた。修正前の状態は `browser-check.json` の `before`。

- 録音の再生中は、見出し・難しさ・範囲を実際の演奏から表示。「録音」と示す。録音の範囲は変更できるように見せず、元の練習範囲は別に保つ。
- 停止と自然な再生終了の両方で、練習中の曲・課題曲の選択・範囲へ戻す。古い録音のラベルや演奏を表示し続けない。
- 録音中は範囲と指揮の操作を無効にし、見えている録音と異なる練習曲の指揮へ切り替わらないようにする。止めると両方の操作が戻る。
- 切り出した範囲に出番がなくても、録音に入っていた部員の顔は席に残す。音を出した部員だけが光る。
- 会場設定を `playRecording` にまとめた。録音一覧だけでなく、卒業式や本人の録音を聴く経路でも保存された会場を使う。

## 確認

- 現在の課題曲「歓喜の歌」の後半を選んでから、《新世界より》第2楽章の前半を録音再生。録音の曲名・星1・前半を表示し、範囲の操作は不可。停止後は課題曲と後半が戻り、切り替えも再び使える。
- 全曲の録音は「全部」、任意に短く切った録音は「録音の範囲」。短い録音が最後まで鳴った後も、現在の曲と操作へ戻る。
- 卒業式の録音開始前は音楽室、再生中は県民文化会館。画面の会場と音側の会場設定が一致し、録音の曲名も表示。
- 出番のない席も含め39人の顔を表示。`check_stage_faces.js` に無音の部員の回帰確認を追加。
- 元の部と録音の内容・自由曲と課題曲の選択・練習範囲を保持。375pxの両テーマで横はみ出し・確認中のエラーなし。
- 構文・差分の空白・字形を確認。字形の不足は従来の記号5字のみ。
- iPhone向けビルド成功。最初のインストールは接続切断、再試行でインストール成功。端末がロック中のため自動起動は未確認。変更したHTML・UI・録音の処理は同梱内容と一致。

採点・成長・演奏の音符やずれ・保存形式は変更なし。素材やフォントの取得なし。確認用ページは本物の保存先を書き換えない。
