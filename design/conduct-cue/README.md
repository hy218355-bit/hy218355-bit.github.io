# 指揮の拍を先に知らせる

最初のタップ前から、2拍先までの丸を表示する。右から近づく丸が左の輪へ重なる瞬間が拍。輪へ向かって縮む外側の輪と、指揮棒の予備の動きも添えた。最初に何回叩いたかは下の小さい丸で示す。到着前は目標の輪に数字を重ねない。

テンポ出しは指定テンポで案内し、タップを始めたら本人の間隔の中央値へ合わせる。演奏の開始後は、実際の音に使う`BeatClock.beatAt`から予告の位置を取る。最初のテンポ決定・演奏の開始時刻・判定幅・指揮の効き・採点・保存形式は変えない。区間の途中から始める場合も、演奏の開始拍を引いて表示する。

演出なし・短く・`prefers-reduced-motion`では、丸と棒を移動させない。固定した2拍先の数字、4つの目印、輪の点灯で拍を知らせ、説明も「輪が光ったらタップ」に合わせる。SVGは開くときに一度作り、表示の更新には従来の`requestAnimationFrame`を使う。新しい音源・素材・通信・保存項目・タイマーは追加していない。図は本作品のために自作したSVG（`img/CREDITS.md`の自作部品に該当）。

タップ面の「大きく」のクラス名が画面見出しの`.top`と重なり、音楽室の画像が入り込んでいた点も修正した。

## 確認

- `check_conduct_cue.js`：2・3・4・8拍の入り、実際の`cdTap`と開始時刻・ぴったり判定の一致、全15曲の区間とテンポ変更、判定幅の維持、時計と演奏の不変、終端と待機・終了、演出なし・短く・動きを減らす設定。
- 375×812のライト・ダークで、最初のタップ前から予告が動く。375×667でもタップ面は高さ172pxあり、横にはみ出さない。
- 実際の同梱音源41個を読み込み、テンポ出し4回→再生→タップ4回→中止を操作。`SampleVoice`で再生し、中止後の部・録音は変更なし。
- 演出なしでも予告の位置は固定される。歓喜の歌の前半で、4回の入りと演奏中の4タップを操作し、4回ともぴったり判定。そのまま自然終了し、指揮の録音が1件残る。部員の情報は変わらない。
- 起動スクリプト33件すべてを読み込み、コンソールの警告・エラーなし。文字の確認は従来の未収録5記号のみ。フォントの取得なし。
