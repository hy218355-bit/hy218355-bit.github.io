# 小節のはじめを予告する

指揮の1拍目を、太い金色の光で2拍先から知らせる。到着線・操作面の縁・下の「1」も金色へそろえる。通常の拍は既存の緑色を保ち、色に加えて太さでも見分ける。

## 直した不具合

「春」の練習区間は54拍目（3拍目）・111拍目（4拍目）から始まるが、従来の予告はどちらも1拍目へ戻っていた。`before.json`は変更前の本当の時計から取った結果。`CD.perf.from`を表示の拍番号へ加え、途中からの数え始め・聞こえた拍の枠も実際の位置へ合わせた。

テンポ出しのクリックも実際の1拍目を強める。2拍子を4回数えるときは1回目と3回目。「春」の54拍目開始なら3回目、111拍目開始なら2回目が強い。金色の意味はテンポを押したTIPSだけに追加し、通常の画面には説明を増やさない。

演奏の時計・入力時刻・判定幅・音符・採点・成長・セーブ形式は変更しない。素材やフォントの取得なし。金色は既存の色名を使用し、新しいアニメーションは追加しない。

## 確認

- 変更前の回帰テストで、2拍子のクリックが1回目しか強くならないことを検出（`before-test.txt`）。修正後は2・3・4・8拍子の音と予告が通る。
- 全15曲のすべての練習区間について、開始と次の2拍を本来の拍番号と照合。実際のBeatClockを使い、テンポ変更・終端・判定幅・保存した指揮の不変も確認（`cue-check.txt`・`timing-check.txt`）。
- ブラウザでは「春」の54〜111拍・111〜140拍を実入力で開始。どちらも4入力すべて「ぴったり」。54〜111拍の自然終了で録音1件が残り、部員データは変化しない。41音源を読み込み、`SampleVoice`で演奏する。
- ライト・ダークで、数え始めと演奏中の1拍目が金色に点灯し、操作面と拍の「1」も同期する。短い点灯は確認用のMutationObserverで記録し、操作待ちで見逃した値を採用しない。
- 375×812の両テーマ、375×667の両テーマをPNGへ保存。小さい画面の操作面は327×72px、テンポ欄の下端は657pxで収まる。演出ふつう・短く・なしをブラウザで確認。動きを減らす設定の固定予告は回帰テストでも確認。
- TIPSを押してもタップ数は増えず、Escapeで説明だけが閉じて演奏が続く。ブラウザの起動33/33、警告・エラーなし（`browser-check.json`・`console-check.json`）。
- 字の確認は既存の未収録5記号（▶♩♮⤓𝄪）のみで、新しい不足なし（`glyph-check.txt`）。
- Release版をiPhoneへ導入・起動し、実行プロセスとHTML・指揮コードのハッシュ一致を確認（`iphone-check.json`）。ミラーリングなし。実機の見え方・音・操作感はオーナーが確認する。
