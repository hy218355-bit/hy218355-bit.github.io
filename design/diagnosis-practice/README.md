# 診断から、その子の練習へ

## 変更

- 合奏の診断の下に「練習を見直す」を追加。最初はたたみ、顔3人を添えた見出しだけにする。詳しい説明はTIPSへ置いた。
- 譜読み・音程・リズム・音色・表現を切り替えると、現在の力が低い部員から3人まで、顔・名前・学年・楽器・G〜Sのランクで表示。個人の能力の数字は出さない。
- 最初は譜読みの間違いがあれば譜読み、なければ診断の4つの力で点が低い項目を開く。診断の点から個人の演奏ミスの原因を推測せず、今の部員の力を選ぶ参考にする。
- 対象は今の合奏の部員。通常の練習ではコンクールの控えも含め、席のない部員は含めない。譜読みは実際に選んでいる自由曲・課題曲で計算する。
- 顔から本人の今週の練習を開く。選ぶ項目に合う練習を一覧の先頭側へ置き、譜読みが進んだ子には合奏を先に出す。おまかせや元の指示の選択は保ち、見るだけでは指示を変えない。曲の配分や練習区間も自動では変えない。
- 選択後は元の診断の顔とスクロール位置へ戻る。Escapeと、開いている練習ボタンをもう一度タップする中止でも戻れる。
- 項目と開閉は同じ週・曲の間は保つ。週・曲・年度が変わったら見直す。録音やお手本の再生中、本番当日、オーディション、できごとへの対応待ち、選曲や冬など練習欄がない場合には出さない。
- 同じ現在の演奏を聴いているときは、再生を止めずに練習を選べる。保存するのは選んだ従来の個別練習だけ。追加の状態はUの一時的な情報で、セーブには足さない。
- 途中の席替えで診断の3人から外れたら、本人が今いるパートの練習行へ戻す。閉じた控えの行も開き、見つからない顔へ切り替えない。

点数・音・伸び方・行事・保存形式の変更なし。既存の顔とSVG、色とフォントを使い、新しい素材の取得はしていない。

## 確認

製品の画面を使い、qa-diagnosis-practice-5から7で確認。最終版は7。確認ページだけセーブと設定の保存を止めた。

- browser-check.jsonに50場面。375×812のライト・ダークで、たたんだ見出し、5項目の顔とランク、練習を開く・選ぶ・中止する操作を確認。
- 5項目の表示順を部員の元データから計算して照合。能力が最も低い席なしの部員を除き、コンクールの控えは通常の合奏に含めた。0人なら欄を隠し、1人でも本人の練習から戻れる。
- 項目の切り替え・移動・中止では部の状態が不変。曲の練習とメトロノームを選んだときだけ、その部員の指示が変わり、能力・録音・診断の値は不変。
- 自由曲と課題曲で譜読みの順番が逆になる部を確認。選んだ課題曲の部員から練習を開き、同じ課題曲の診断へ戻れた。配分は変えていない。譜読みSの子では合奏を先に出すが、自動では選ばない。
- 通常の合奏38人の再生を保ったまま、項目・練習を切り替えて同じ再生へ戻れた。過去の録音では欄を隠し、停止後は現在の部員で戻った。
- TIPSのEscapeは説明だけを閉じ、次のEscapeで見直し欄を閉じる。タップで練習欄を閉じる場合の戻り先を失う問題も修正し、最終版で戻る顔と曲を確認し直した。
- 320×568の12文字の名前も枠内へ。3人の顔は合奏の操作より上。再生中の小さなバーがある練習画面でも、メニューが固定ボタンと重ならない。
- 4タブ×両テーマで横幅375px、項目と部の状態を保持。見直し欄は合奏だけに表示。行事の部員を選んだ途中でも、診断から移動して中止すると、その選択を保ったまま戻れた。
- 演出のふつう・短く・なしを実際に切り替えて移動と復帰を確認。端末の動きを減らす設定は既存のfxCalmを使う。OS設定の切り替えは実施していない。
- 1200pxでも横のはみ出しがなく、本人の練習を閉じると元の顔へ戻れた。
- 練習を開いた後に本人を控えへ移し、診断から外れた状態で中止。今週の控えの行が開き、本人にフォーカスが戻った。席替えを元に戻すと部の状態も復元され、通常の練習の決定では診断の顔へ戻った。画像はscreenshots/moved-member-light.png。
- 初年度を実際の68操作で2026年4月から2027年4月まで進行。練習の32場面では見直しが可能、残り36場面では練習欄も見直し欄も非表示。本番と冬・卒業の判定は、顔だけのデモではなく年度の実際の進行で確認した。
- 50場面と年度の全場面でスクリプト33/33、エラーなし。コンソールの警告・エラー0件。
- 現在の演奏を作り直す・今の本人の試聴・停止後に今の週へ戻す既存確認が成功。構文・差分確認成功。字形確認は既存の不足記号5字のみ。

年度はyear-flow.json、タブはtabs-check.json、演出はmotion-check.json、コンソールはconsole-check.json。PNGは通常375×812、小さい画面は320×568で、全て1枚200KB以内。
