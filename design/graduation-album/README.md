# 顔から、卒業する本人をふり返る

## 変更

引退前は同じ13人の名前が繰り返し並び、顔が見えるまで文章が続いていた。卒業式の表紙と最後も文章だけだった。

- 引退前は3列の顔一覧にし、名前・楽器の印・いちばん伸びた力のG〜Sを表示。押した本人だけを大きく開く。成長のすぐ下に44px以上の録音ボタンを置き、思い出と最後の言葉はその後に残した。
- 名前の羅列を人数に置き換え、最初の代の物語と年ごとの記録は一覧の下で開く形にした。入部時と最後の全員の録音も、その中に残している。
- 3月の画面・卒業式の表紙・最後に、本人を選べる集合写真を配置。どの顔からでも、その人の名前・顔・成長・思い出へ移れる。選んだ本人は自動で送らず、読んでいる間は止める。
- 前へ・次へ・閉じる操作は保持。選んだ本人の名前へフォーカスを合わせ、閉じたら元の顔やボタンへ戻す。最後の決定後は年度末の操作へ移す。
- 冬へ進む操作と3月の操作をスマホの下に固定。録音の再生バーとは重ねず、ほかのタブでは隠す。
- 演出ふつうでは表紙の集合写真を9秒見せ、短くは従来の3.5秒。なし・端末の動きを減らす設定では自動送りをしない。

点数・成長・できごと・録音・顔の配役・セーブ形式は変更なし。既存の顔とSVGを使い、外部ファイルやフォントの取得はしていない。

## 実際の画面で確認

本物のセーブと設定を変えない確認画面で実施。`browser-check.json`に45場面、`tabs-check.json`に4タブ×両テーマ、`year-flow.json`に年度の進行68操作を保存した。

- 375×812のライト・ダークで引退一覧、個人の成長と音、3月、卒業式の表紙・本人・最後を確認。
- 一人だけを開き、本人の音1人分と全員の録音39人分を再生。選ぶ・開く・聴く操作では部の状態・力・録音が変わらない。
- 実際に3年生13人を引退させた後も、卒業式の録音は当時の39人。顔を選んでも録音の再生位置を保つ。
- 13人全員を順に表示し、本人のid・名前・顔の原画が一致。前後への移動、集合写真から見直す操作、閉じたときの元の顔へのフォーカスを確認。卒業の決定前は保存内容が不変。
- 最後の決定後も力・録音はそのままで、2029年度まで進められる。
- 入部時の記録なし・控え・12文字の名前でも表示できる。録音のない控えに再生ボタンは出さず、ほかの部員の古い録音は44pxのボタンで聴ける。改名しても元の顔を保つ。
- 39人の卒業生と320×568でも最後の本人まで選べる。集合写真はカード内でスクロールし、下の操作は画面内に残る。横はみ出しなし。
- 演出ふつうの自動送り、短くの0.2秒の切り替え、なしの0秒を確認。顔の選択や記録を開く操作で自動送りが止まり、同じ本人を読める。
- 卒業生がいない初年度も、2026年4月の担当決めから本番・人選・入部・定期演奏会・アンサンブル・3月・2027年4月まで実際のボタンで進行。3月は顔一覧を出さず「1年をふり返る」と表示。
- 4タブの両テーマで幅375px、内容幅375px。固定の操作は今週だけ表示。コンソールのエラー・警告は0件（`console-check.json`）。各場面は33本のスクリプトを取得し、操作中のエラーなし。
- 顔の原画は最大10枚を再利用。字形チェックは既存の不足記号5字のみ。

`check_graduation_album.js`では、実際の本人選択・前後・終了・保存・タイマーの関数を使う。本人選択で卒業を決定せず録音を再開しないこと、最後の決定だけが保存すること、記録と部員を保つこと、演出3設定と動きを減らす設定を確認。既存の個人録音・顔100人・舞台の顔の確認も通過した。

表紙と個別の卒業画面はPNG。一覧など大きい画像だけは画素を変えずにWebPへ変換した。すべて375×812、1枚200KB以内。
