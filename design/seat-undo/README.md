# 直前の席の移動を元に戻す

- 移動した本人・交代相手のカード上部に「元に戻す」を表示。直前の1回だけ、移動前の状態を保存し直す。二人の席・音程・音色だけでなく、移動の日誌や160件上限で消えた先頭の記録も元に戻す。
- 取り消し用の情報はUIの一時メモリのみ。セーブ形式に追加しない。改名・練習・指揮の録音など、commitで保存する次の操作で消す。元の状態との対応も確認する。再読み込みを越えて持ち越さない。
- 取り消し時は再生・読み込み待ちを止め、元の試聴とパートを戻して合奏を作り直す。停止のコールバックで別の操作が保存されたら取り消さない。
- 移動による能力の変化、採点・成長の式は変更なし。素材・フォントの取得なし。

## 確認

- check_member_move_undo.jsで交代・控え・空席・160件の日誌・録音・セーブと再読み込み・試聴設定を確認。直前の1回だけを戻し、改名・練習・本番・停止時の保存を消さない。
- 375×812のライトとダークで、交代と控えへの移動後のボタンを確認。取り消すと全員の席・能力・顔・録音を含む元の状態へ一致。改名・部の方針の変更後は取り消しを終了（カードを描き直さない操作でも古いボタンを残さない）。音の読み込み中でも取り消せ、読み込み完了後に古い編成が鳴らない。横はみ出しと確認中のエラーなし。
- 顔・名前の既存回帰確認、構文、差分、字形を確認。字形の不足は既存の記号5字のみ。
