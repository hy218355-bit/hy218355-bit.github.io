# 指揮B案の反映

オーナーが選んだ「B・舞台の中へ」を実ゲームへ反映。舞台を画面幅まで広げ、青緑の背景・右から来る光・固定したライン・横長のタップ面を組み合わせた。合図は操作面の上に置き、最後まで隠れない。上・下の強弱は327×80pxの面の中で操作する。375×667では高さ72pxへ縮める。

曲名と会場を分け、説明と数字を減らした。顔・楽器・能力のランクは既存の表示を保つ。指揮中の床の細い線は減らし、部員と合図へ目線を集める。顔の画像の使い回しと、SVGを開いたときだけ作る処理を維持。新しい素材・フォントの取得なし。

## 確認

- Chromeの375×812でライト・ダーク、375×667でも両テーマを確認。横のはみ出しなし。327px幅の操作面とテンポが同じ画面内に収まる。39人の顔と楽器を表示。
- 実際のクリック4回で演奏開始。キーボードで4回続けた4拍子はすべて「ぴったり」。2拍子でも開始・判定でき、操作面の上で強弱1.37、下で0.59へ変わる。数値は診断記録のみで、画面に追加していない。
- 中止で部員と録音が変わらない。自然終了で録音1件が残り、結果へ進める。録音再生の操作も受け付ける。
- 「短く」「なし」では光の位置が固定され、ライン・タップ面・拍が点灯する。動きを減らす設定と2・3・4・8拍、全15曲の区間とテンポ変化は`check_conduct_cue.js`で確認。
- 入力の処理待ち補正は`check_conduct_timing.js`で回帰確認。判定幅・指揮の効き・採点・成長・セーブの形式は変更していない。
- 本番を聴く画面ではタップ面を隠し、顔から本人のカードを開ける。確認ページで4月から新年度まで49操作を進め、2027年へ到達。起動33/33、コンソールの警告・エラーなし。
- 字の確認は以前からの未収録5記号（▶♩♮⤓𝄪）のみ。新しい不足なし。
- Releaseビルド・iPhoneへの導入・起動成功。実行プロセスと変更した3ファイルの同梱ハッシュも確認。ミラーリングなし。実機の画面・音・操作感はオーナーの確認に任せる。
