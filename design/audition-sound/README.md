# 人選で響きが変わる理由を見せる

- オーディションの予想欄に「安定感・厚み・楽器」の印を追加。色と点の数で区別し、読み上げには状態の言葉も渡す。押すと理由を開く。常時表示する文章を短く保ち、従来の「予想の見方」の場所を使った。
- 同じ予想の演奏を分析した `disruption`・`fullness`・`thin`・`lack` を使う。A部門は、既存の課題曲4割・自由曲6割で合わせる。欠けた楽器の名前は両曲から集める。
- 採点式・成長・音・当日の出来・人選おすすめ・個人のG〜S・保存形式は変更なし。理由の数値は予想の一時的な返り値に追加するだけで、保存しない。新しい素材やフォントの取得なし。
