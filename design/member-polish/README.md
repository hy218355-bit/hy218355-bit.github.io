# 顔と成長が見える部員の画面

- パート欄を3列にして約297pxの高さへ。大きな棒をG〜Sの4文字に置き換え、楽器の自作アイコンも使用。ランクの順は音程・リズム・音色・表現のまま、説明は「？」へ置いた。
- 名簿の顔を40px・名前を14pxへ。役と学年・楽器を残し、癖やスキルの長い説明はカードへ。最初の375pxの画面で、フルートの4人が見える。
- 名前を本物のボタンにし、Enterでもカードを開ける。カードへフォーカスを移し、閉じると選んだ部員と元のスクロール位置に戻る。閉じるボタンは自作SVGと44pxの操作範囲。
- カードは同じ112pxの原画と楽器、本人のひとことを上に。4つの力を入部時→今のランクで並べ、変わらない力も省略しない。成長が記録されていない旧セーブは、現在の4つのランクを表示する。
- 譜読み・スキルと癖・思い出は折りたたみ。夢と恋、本番の強さは常時見える。席を移す機能も保持。
- 元の顔・名前・点数・成長・セーブの形式は変更していない。ネットからの読み込みや素材のダウンロードなし。合奏のカードへ動くときも、演出の設定に合わせてスクロールする。

## 確認

- 375pxのライト/ダークで名簿とカードを確認。4つのタブも横にはみ出さない。
- 全39人に同じ配役の顔があり、名前のボタンは48px以上の高さ。
- 最後の部員を開いて閉じると、同じ人のボタンにフォーカスが戻り、画面内の位置も維持。
- Enterでカードを開き、閉じるボタンへフォーカスが移ることを確認。
- 折りたたんだ譜読み・スキル・思い出を開いて読める。「この人だけ聴く」で実際に再生され、全員の音へ戻す操作も表示される。
- 新入部員の夢とG→G、入部の記録がない旧セーブ、席のない控えも表示できる。
- 4月から新年度まで49回の画面更新で進行し、2027年度へ。確認中のエラーなし。
- `node tsukurikata/tools/check_faces.js`、`node tsukurikata/tools/check_stage_faces.js`、JavaScriptの構文と `git diff --check` が成功。
- `python3 tsukurikata/tools/check_glyphs.py`：既存の不足記号5字のみ。新しい不足文字なし。

詳細は `screenshots/checks.json`、iPhoneのビルド・起動・同梱ファイルの照合は `iphone-build.json`。実機の見た目はオーナーが確認する。
