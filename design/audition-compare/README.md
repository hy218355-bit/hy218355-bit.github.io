# 人選の違いを全員と見比べる

- 選んだ人で出る予想に、全員で出る場合との点差を表示。表示している小数1桁の点同士の差を使う。全員を選んだときや0人のときは比較を出さない。
- 安定感・厚み・楽器に、全員からの変化を示す上・下・横の印を添える。安定感は乱れの減点、厚みは薄さの減点と厚みの加点の合計、楽器は欠員の減点を比べる。0.05点未満の違いは同じとして扱う。今の3段階の印も保持し、向きと読み上げ文で色以外からも分かるようにする。
- 比較の説明と全員の点は既存の折りたたみ内に置く。全員の予想は同じ部の間で1回だけ作り、編成などを変えたら作り直す。
- 同じ週の移動後に古い編成の予想を返す不具合も修正。予測のメモが週・人数などだけを見ていたため、39人から38席になっても以前の39席の演奏を使っていた。入力の部も同じ場合にだけメモを使うようにした。
- 採点と成長の式、おすすめの探し方、保存形式は変更なし。素材とフォントの取得なし。

## 確認

- check_prediction_state.jsで不具合を再現。修正前は予測の人数が39、計算し直すと38。修正後は両方38になり、席・楽器・曲・やる気を変えた新しい部でも計算し直した結果と一致。
- ブラウザ375×812の両テーマ。見本の全員37.7点→選択67.3点で+29.6点。安定感は上、厚みは同じ、楽器は下。安定した打楽器を外すと−1.4点になり、厚み・楽器が下になることも確認。
- 全員へ戻すと元の点、比較は非表示。全員のチェックを外すと予想を消して決定不可。選択中は保存内容が不変。A部門も課題曲4割・自由曲6割のモデルと一致し、おすすめの選択は従来の関数と同じ。
- 同じ週に席を控えへ変え、人選を開き直すと、全員の基準も37.3点から38.0点へ更新。横はみ出しと確認中のエラーなし。
- 全15曲の人選と同じ本番の採点・理由、席の取り消しの回帰確認。全15曲をSIM_SEED=20261026、N=10、3年、おまかせ・おすすめで早送り。平均点・平均人数はdesign/score-balance/final-a.txtとfinal-b.txtを合わせた変更前の結果と一致し、1年目37〜47・2年目55〜67・3年目65〜75点の範囲内。simulation-check.jsonに記録。
- 構文・差分・字形を確認。字形の不足は既存の記号5字のみ。確認用ページは本物のセーブを書き換えない。
