# 39人の顔のバランスを修正

2026年10月26日。オーナーの意図は男女の人数比ではなく、39人の原画の中で「女子8人がかわいい・男子1人だけがかっこいい」という内訳。残り30人は自然な顔立ちと個性を持つ部員にした。

[39人の比較を見る](index.html)

## 変更

- 前の39種類を、整った女子8人・男子1人、自然な顔立ちの30人へ整理。直前の原画セットの女性31人／男性8人の構成は維持した。
- 自然な顔は、以前承認された高1寄りの原画を使う。普通の男子4人を追加し、丸顔・面長・細い目・眉・鼻・口・眼鏡などを個別に描き分けた。小さい表示の読みやすさと高1の年齢感を保つ。
- かわいい8人と、かっこいい1人は前回のなめらかな原画を使用。ほかの部員も親しみのある表情にした。ゲームには外見の評価ラベル・能力・特別な枠を追加しない。
- 39人の配役を `js/face-cast.js` と `img/faces/manifest.json` に明記。原画のどの枠を使うかの情報だけで、セーブには入れない。
- 誤って追加した「新入部員を女性4：男性1にする」処理を削除。名前生成は比率変更前と同じ処理に戻した。既存の部員・入部待ち・卒業生の名前は変更しない。名前と顔の対応は維持する。
- 原画の解像度を保つWebP表示を維持。SVGへの減色・ベクター変換は行わない。各画像は200KB以下で、iPhoneにも同梱する。

## 素材

既存の高1寄りの原画3枚と、前回の描き直し1枚を再利用。追加した普通の男子4人は組み込みimage_genで制作（CLI不使用）。追加の最終プロンプトは [prompts.json](prompts.json)。原稿の場所・圧縮品質・画素数・容量は [manifest.json](../../tsukurikata/img/faces/manifest.json)。外部作品やダウンロードは使っていない。`tools/build_faces.py` で元の画素数のままWebPへ圧縮する。

## 確認

- `node tsukurikata/tools/check_faces.js`：39個の異なる原画の枠、女子8人・男子1人・残り30人、名前生成200人が比率変更前と同一、すべての既存名と顔の対応、進級時の顔の維持、旧セーブ不変、キャッシュ、画素数と容量を確認済み。
- 375pxで、ライトの部員カード・一覧・今週・相談・指揮・卒業式・入部の7画面を確認し、PNGを `screenshots/` に保存。ダークのゲーム本体でも5人の顔が表示された状態を確認した。`checks.json` と `actual-game.json` に記録。
- 点数・伸び・イベント・セーブ形式を変更しない。`band.js` の差分は、名前と顔を合わせる配役表だけ。
- ブランチは `codex/design`。元のClaudeの作業フォルダを編集せず、pushしない。

Releaseビルドに成功し、同じiPhoneへ更新して起動した。`screenshots/iphone-build.json` のとおり、同梱したHTML・顔の配役表・顔の描画・名前の処理・原画が作業内容と同一である。
