# 指揮UIを作り直す案

現行の画面は、舞台の顔の密度と大きな四角い操作面に比べて、実際の合図が小さく、棒・丸・説明・数字へ目線が分かれていた。今回はゲームのファイルを変更せず、指揮の見た目を2案で比較する。

## A · 真ん中でタップ（おすすめ）

「部員と息を合わせて、ひとつの拍を叩く」。39人のうち3人を手前に大きく見せ、顔と名前を近づける。操作は中央の142pxの丸にまとめ、光の輪が近づいて届く動きで予告する。四角い枠・独立した棒・重複する数字を外し、部員とタップを主役にした。

紙色と紺のインクを残し、金は合図や反応に絞る。青緑を薄く添える。ライトでは紺のタップ、ダークでは明るいタップに反転し、操作面を見失わない。全体を作り直す際にも既存の画面へつなげやすいため、おすすめ。

## B · 舞台の中へ

「39人の音を動かす」。舞台を大きく見せ、合図は横から届く光へ。到着するラインと、その下の横長のタップを組み合わせる。広い327×64pxの操作面を下へ寄せ、演奏に入り込む方向。ダークは夜の舞台、ライトは青緑の明るい舞台。

## モックの範囲

- `index.html`はタップ・キーボード・テーマ切替・合図の音を試せる画面。上部の戻るボタンは`gallery.html`へ戻る。モバイルの画面外のデザイン選択はギャラリーのリンクから行う。
- 画面で4回タップすると、演奏中を想定した反応へ移る。判定の表示はモック内の80BPMの拍による見本。実際のゲームの指揮・採点・音源・セーブにはつながない。
- `still=1`は画像確認用に一定の拍で止める指定。通常は光が2拍先から近づく。動きを減らす設定では移動する輪を隠し、横の光は固定して、拍の点灯と数字で知らせる。
- 部員の顔は既存の100人の原画を`Faces`から表示。3人を手前へ出すのは見せ方のサンプルで、能力や顔の配役をゲームに変更していない。新しい絵のダウンロードなし。
- フォントは同梱のZen Kaku Gothic New 400・700。部品と楽器の線は自作SVG、色はCSS変数から使う。新しいフォントの取得なし。
- 375×812のライト・ダークで両案を確認。横にはみ出さず、タップと下の操作が画面に入る。主要なヘッダー・音のボタンは44px、主操作はAが142px、Bが327×64px。

スクリーンショットは実際のHTMLを撮影したPNG。ゲームへの反映はオーナーが案を選んでから行う。ミラーリング・実機への導入は行っていない。変更は`design/conduct-redesign/`だけ。
