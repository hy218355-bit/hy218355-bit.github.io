# 休みの部員を、無音で試聴しない

ラルゴの前半で休みのピッコロを押すと、音がないまま「再生中」の金色とチェックが付いた。`before.json`は実ブラウザで本人だけを再生し、実際に聴こえる部員が0人だった記録。

## 変更

- 今の部員カードも、その練習区間の音符と打楽器の音で出番を判断する。本人の試聴を「この範囲は休み」（全部なら「この曲は休み」）に替える。
- 同じパートに出番があれば、パートの試聴は残す。休む本人の顔・席・ランクも残す。
- 「聴き方」の対象を、今の演奏に音のある本人とパートにそろえる。区間変更で音のない指定が残ったら全員へ戻す。
- 区間が変わってもカードとボタンを作り直さず、入力中の名前や開いた成長・思い出を保つ。消える操作に操作先があった場合だけ、残るパートか閉じるへ移す。
- まだ演奏を用意できていない瞬間に押しても、作ってから出番を確かめ、無音の試聴を始めない。

既存の演奏ごとのWeakMapを共用する。顔・能力・席・譜面・音・採点・成長・録音・セーブ形式を変えず、保存する項目も追加しない。録音側の出番判定はそのまま。新しい画像・フォント・動く演出・外部取得はない。

## 確認

- `check_current_rest.js`：全15曲・57区間・39人。休み延べ301人、出番あり延べ1,922人、パートの休み41件。休みを試聴しないこと、本人とパートの区別、一覧、無音の指定の解消、未準備時の判定、操作先、演奏の使い回し、部・音・録音の不変を確認。
- 実ブラウザ21状態：ラルゴ前半は全員の18人で演奏し、ピッコロの顔を残す。全部へ戻すと本人1人の音を聴ける。天国と地獄の中間ではピッコロは休み、フルート3人を聴けて、同じボタンで全員37人へ戻る。区間変更で前の本人だけの指定を解消する。
- 3ボタンに付けたWeakMapの番号を照合し、同じ本人の区間変更でボタンを作り直さないことを確認。未保存の名前と開いた成長・思い出が残り、部と録音のハッシュも変わらない。
- 曲全体を休む打楽器のカードも確認。パートの読み込み待ちから音のない前半へ変えると、中止して全員へ戻る。音源を解放しても古い待機は鳴らない。
- 375×812・375×667のライトとダークで、操作44px以上・横のはみ出しなし。舞台は休みの子を含む39人のまま。
- 49操作で4月から2027年度へ。33スクリプトの起動に成功。4タブ375px、コンソール警告・エラーなし。
- 本人の試聴、録音の休み、お手本の文脈、停止後の最新表示、曲の試聴の既存検証も合格。`*-check.txt`に保存。
- 字の検査は既存の5記号（▶♩♮⤓𝄪）とコメントの「常」「了」「奪」を報告。休みの表示は既存の録音カードと同じ文言で、新しい字を増やしていない。

`browser-check.json`に操作直後の状態、`browser-assertions.txt`に音・一覧・ボタン・保存内容の照合を保存。QAは本物のセーブと設定を変えない。`audioRange=1`はこの確認ページ専用の開始区間で、製品には含めない。
