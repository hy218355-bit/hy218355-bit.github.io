# 席替えの前後を顔と楽器で確認する

席を選ぶと、その下に移動後の二人の席とランクを表示していた。375pxではその確認欄が画面の外に残り、固定の「移す」だけ押せる状態だった。元の席も確認欄に出ていなかった。

## 変更

- 二人それぞれの顔と名前の下に、元の席→移る席を楽器のSVGとともに並べる。移る先を金の枠で示し、読み上げにも移動の向きを含める。控えと空席も同じ形で扱う。
- 変わる音程・音色のランクだけ、G〜Sの前後を並べる。同じ楽器内の交代や控えなど、ランクが変わらないときは重ねて表示しない。
- スマホで選んだら確認欄が固定ボタンより上に見える位置へスクロールする。再生バーがあるときは余白を増やす。スクロールの動きは既存の端末と演出の設定に合わせる。
- 320pxではランクと余白を少し詰め、二人の確認がボタンに隠れないようにする。選択のチェックに長い名前を重ねない。
- 幅変更の確認中に舞台の`ResizeObserver`の警告を記録した。サイズの通知中に直接高さを書き換える描画を、次の描画フレームへまとめた。

席替えの能力変化・点数・成長・セーブ形式・顔の配役は変更なし。既存の`moveMember`から予告を作り、確定するまでは保存しない。

## 確認

本物のセーブを使わない確認画面で、実際のボタンを操作した。`browser-check.json`に記録。移動前後の全員の席・ランクを比較し、記録にはそのSHA-256と対象者の内容を残した。

- 375×812のライト・ダークで、顔、元の席、移動先、変わるランク、固定ボタンを確認。確認欄は下端662px、固定バーは上端682pxで重ならない。
- 320×568・375×667・768×1024でも二人の確認が固定バーの上に収まり、ボタンの中心で実際に「移す」が当たる。横はみ出しなし。
- 1280×900では通常のページ内の配置。キーボードで確定ボタンまで移動でき、表示されたボタンの中心でも「移す」が当たる。
- 再タップで解除し、選んだだけでは部の状態が変わらない。実際に交代すると全員の席・ランクが予告と一致。「元に戻す」で元の部の状態と一致する。
- 控えへの移動、控えから空席への移動も予告と一致。空席への移動の取り消しも一致。同じ楽器内では変わらないランクを表示しない。
- 再生中、部員一覧から席を選んでも確認欄・移動バー・再生バーが重ならない。移動バーと再生バーの間は10px。
- 本人と相手の名前を12文字に変えても、375pxで横はみ出しなし。本番中は選んでも確定ボタンが無効で、部の状態も変わらない。
- 最終版で320→375→768→1280→375→768→320→375pxと幅を変え、毎回選択を切り替えた。起動の33本すべて取得、操作中のエラー・描き直しの警告なし。修正前の警告も記録に残している。
- 既存の席の取り消し・名前の保持・舞台の顔の確認を実行。字形チェックは既存の不足記号5字のみ。外部ファイルのダウンロードなし。
