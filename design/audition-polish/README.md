# 人選を、顔と音で決める

- オーディションに36pxの顔と自作の楽器アイコンを添えた。個人の当日の出来は元の点をG〜Sへ置き換えて表示し、数字は出さない。元の点は予想やおすすめの計算にそのまま使う。
- 出る人は金の線・淡い背景・チェック、控えは点線・「控え」の文字で区別。控えも名前と出来を読み比べられる。本人の試聴は44pxの再生ボタン。
- パートを閉じても選んでいる部員の顔を最大3人表示。全員が控えなら、顔を淡くして人数を示す。
- 全員・おすすめ・一人ずつの選択でリストを作り直さず、開いたパート・フォーカス・位置を保つ。チェック、線、出場人数とパートの人数は同じ選択からそろえて描く。
- 部全体の予想点と賞をまとめた。説明は「予想の見方」と人選の吹き出しへ。予想の説明も選び直しで勝手に閉じない。計算はそのときの部と選択に対応させ、古い結果が別の画面へ出ないようにした。
- 決定ボタンは下のタブの上へ。再生中は再生バーの上へ移動。0人では決定とメンバーの試聴を止め、選び直しを案内する。「全員出る」で戻せる。
- 5人では全員をそのまま見せ、12文字の名前も全文を折り返す。決定済みの人選を編集するときは「変えずにもどる」を使える。
- 採点・成長・当日の出来・予想・おすすめの選び方・人選決定時の効果・顔の配役・保存形式は変更なし。素材・フォントのダウンロードなし。

## 確認

- 375pxのライト・ダークで人選、少人数、長い名前を確認。4タブの両テーマでも横幅375pxに収まる。
- 全員の予想点とおすすめの人選が、従来の `predictContest`・`recommendLineup` の結果と一致。
- 一人を控えにするとチェック・線・文字・人数がそろって変わる。キーボードで選び直しても本人の位置とフォーカスを保つ。
- 全員・おすすめの操作でも開いたパートと予想の説明を保ち、週・部員の力・オーディションの出来を変えない。
- 決定した出場と控えが実際の部員に保存され、取り消しでは決定済みの人選を変えない。
- 39人全員を外すと、決定とメンバーの試聴ができなくなる。0人から全員に戻せる。
- 本人の試聴がその人の名前で開く。再生バーの上端696pxに対して決定ボタンの下端690pxで重ならない。
- 5人の顔とランク、12文字の名前、全39人のG〜Sと元の点の対応を確認。
- 4月から新年度まで50回の画面更新で2027年度へ進み、確認中のエラーなし。日誌も全文を保つ。
- JavaScriptの構文、顔・舞台・名前の既存チェック、`git diff --check` が成功。字のチェックは既存の不足記号5字のみ。
- iPhoneへのビルド・インストール・起動が成功。変更した2ファイルは同梱ファイルと一致。実機の見た目はオーナーが確認する。
