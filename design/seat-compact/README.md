# 席を、すぐ選べるように

## 変更

- スマホの楽器9種類は全て最初から見せ、アイコンと名前を横に並べた44px以上のボタンへ。375pxでは一覧の高さを54px減らした。文字の大きさは11pxのまま。
- 「席を移す」を開いたら、移動先の顔が見える位置へ移動。楽器の切り替えと選択解除でも先頭から選び直せる。本人の大きな顔と名前はすぐ上に残す。
- 未選択の「移す」は背景と線を灰色にし、透明度で金色を薄める見せ方をやめた。有効な移動先を選んだときだけ金色にする。本番中は選択しても灰色で押せない。
- 選択のチェック、二人の席とG〜Sの予告、確定・中止・停止の位置、直前の移動を元に戻す操作は保持した。
- 画面の文章・点数・伸び方・移動の効果・保存形式は変更なし。追加素材・フォントの取得なし。自動の移動は既存のfxCalmと演出の設定に合わせる。

## 確認

製品と同じスクリプトを使うqa-seat-compact-3で確認。確認ページだけセーブと設定の保存を止めた。

- browser-check.jsonへ31場面、tabs-check.jsonへ4タブ×両テーマを記録。375×812のライトとダークで、9種類の楽器と最初の移動先が画面内に表示された。
- 選択・解除・楽器の切り替え・中止で部の状態が不変。楽器を切り替えると移動先は未選択へ戻り、確定ボタンも灰色へ戻る。Escapeでは欄を閉じて本人のカードへ戻った。
- 確定後の全員の席・ランク・顔が既存のmoveMemberによる予告と一致。元に戻すと部の全体の状態も元に戻った。
- 実際に39人の音が再生中の席替えも確認。確定すると再生と待機が止まり、移動と取り消しの結果も一致した。
- 控えから空席への移動と取り消しを確認。本番の発表待ちでも選ぶだけでは状態を変えず、「移す」は無効のまま。
- 320×568で9種類全て44px以上、最初の移動先は固定ボタンより上。部員一覧から開き、再生中の小さなバーがある場合も確定ボタンと重ならない。12文字に改名した相手の名前と顔・予告も枠内に収まった。
- 4タブを行き来しても部や音は変わらず、隠れた部員カードの席移動ボタンを別のタブへ出さない。両テーマとも横幅375pxのまま。
- 1200pxの大きい画面では従来の62pxの楽器ボタンを保ち、欄を開いてもスマホ用の先頭への移動を行わない。横のはみ出しなし。
- スクリプト読み込み33/33、画面エラーなし。コンソールの警告・エラーなし。
- check_member_move_undo.jsとcheck_current_member_listen.js成功。構文・差分チェック成功。字形チェックは既存の不足記号5字のみ。今回の画面の文字は変更していない。

年度の進行は直前の行事の改善で初年度69操作を確認済み（../outing-faces/year-flow.json）。今回の差分では席を選ぶ表示と操作を中心に確認し直した。PNGは全て1枚200KB以内、通常375×812、小さい画面は320×568。
