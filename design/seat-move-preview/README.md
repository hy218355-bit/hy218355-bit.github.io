# 席を移す前に、二人の行き先とランクを見せる

- 最初は「移す先を選ぶ」で決定不可。控えへ移す場合も明示的に選ぶ。すでに控えの部員に控えは出さない。
- 選ぶと本人と交代相手の顔・名前・移動後の席、音程と音色のランクの前後が出る。長くて選択欄で切れた名前・楽器名もここで読める。数値の能力は出さない。
- 予告は既存の `moveMember` が返す複製から取り出す。能力が下がる式などのゲーム処理は変えていない。選択中の予告を保存せず、決めるときに同じ処理で改めて計算する。未選択・無効な席・同じ席・本番中は決定しない。
- 素材・フォントの取得なし、保存形式の変更なし。顔は既存の部員のものを使う。

## 確認したこと

- 375pxのライト・ダーク。横はみ出しなし。長い打楽器名・交代相手の名前が読める。
- 選ぶ前は決定不可、予告なし。選択しても元の状態を保つ。
- 楽器が違う交代は二人の予告と移動後の全員の席・ランク・顔が一致。同じ楽器の交代はランクを下げない予告。
- 控えと空席は一人の予告になり、決定後の全員の席・ランク・顔が予告と一致。
- 決めずに閉じて別の部員を開くと未選択へ戻り、保存内容は変わらない。部員一覧から開いても横幅375px。
- 本番の発表待ちでは、移動先を選んでも決定不可。確認中のエラーなし。
- JavaScript構文、差分の空白、字形を確認。字形は既存の不足記号5字のみ。
- iPhoneへビルド・インストール・起動済み。最終のHTMLとUIファイルが同梱内容と一致。実機の見た目はオーナー側で確認。

確認用ページは本物のセーブと設定を書き換えない。記録は `browser-check.json`・`iphone-build.json`。画像は375×812のPNG。
