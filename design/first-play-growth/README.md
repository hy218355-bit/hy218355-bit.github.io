# 最初の一歩と、育った音

オーナーの「1–2よろしく」に対応。初見確認は、その後の「今回は初見を想定した検証まででよい」に従い、実際の初見参加者を集めるテストは行っていない。

## 初見を想定した確認と修正

| 見つかった点 | 修正・確認 |
| --- | --- |
| 最初の楽器決め中に、上の見出しが選曲会議だった | 現在の操作に合わせて「楽器決め」と表示 |
| 楽器決め前でも無音の合奏・指揮を始められた | 部員に席がない間は操作を無効にし、先生から楽器決めへ戻れる |
| 「曲を選ぶ」が試聴ボタンへ移る理由が分かりにくい | 「曲を聴いて選ぶ」とし、「お手本で聴く／決めるで選ぶ」を短く案内 |
| 得意な曲の光る枠が、初回案内の移動先と違った | 初回案内中は先頭の曲へそろえる。選曲は自動で決めない |
| 最初の練習が音へどう返ったか気づきにくい | 案内から4月と今の聴き比べへ直接移る |
| 全員を控えにすると、聴く音がなかった | 部員の席を決める操作へ案内する回復経路を追加 |
| 演出なしでも、次のボタンの枠が動いていた | 演出なし・短くでは静止。動きを減らす設定も保持 |

375pxのライト・ダークで、楽器決め → 選曲 → 最初の練習 → 聴き比べ → 最初の本番 → 結果 → 次週を実際の画面操作で確認。ダークではEnterでの聴き比べも確認。両テーマの4タブとも横幅375pxで、横にはみ出さない。

## 育った実感を音で確かめる

合奏の「音の成長を聴く」から、同じ曲の4月と今の部を短く交互に聴ける。

- 今年・同じ曲の4月の記録を使う。ない場合は欄を出さず、記録は作り足さない。
- 範囲・テンポ・抑揚・会場・音のさいころをそろえる。部員・担当・譜読み・体力はそれぞれの時点のまま。
- 能力・音量・採点の係数は上乗せしない。人数や体力が変わった分も実際の音へ出る。
- 育った出場者は最大3人、顔と本当のG〜Sで示す。ランクが変わっていない場合は同じランクを二度並べない。
- 舞台と部員カードは聴いている時点の本人を表示する。音が鳴る直前の待ち時間にも、今の名前・学年・担当へ入れ替わらない。
- 各ボタンは48px。再生中・読み込み待ちは金の枠と停止の印で示す。同じボタンで止められる。
- 部を更新したときや、会場を変えたときは古い比較を止める。録音の読み込みを中止したあとも、後から古い音を鳴らさない。
- ゲームの保存形式・点数・伸び方・過去の録音は変更しない。比較用の音2つだけを画面のメモリに使い回す。

全15曲で同じ最初の5人を1週間練習させ、同じ条件の短い演奏に成長が反映されることを確認。部員の改名・席替え後も4月の記録を保つこと、記録がない場合・違う曲・去年の記録を混ぜないことも確認した。数値の記録は開発確認用で、ゲームの部員の力はG〜Sのまま。

`before-after.wav` は実際の楽器の録音音源で作った確認用音声。4月の5人 → 1秒の間 → 4週間後の7人の順。両方とも同じ曲・テンポ・音楽室を使い、音量の補正はしていない。音割れはない。アプリにはこの確認用WAVを同梱しない。音源の出典は [楽器の音の出典](../../tsukurikata/snd/CREDITS.md) とゲーム内の表示に従う。
