# 録音の休みも、顔から分かる

## 見つかった不具合

《新世界より》第2楽章の前半では、録音当時の39人のうち21人に音符・打楽器の出番がない。その部員のカードでも「この人だけ聴く」が押せて、録音全体が無音になっていた。`before.json`に、実際に音の対象が0人になった状態を記録。

## 変更

- 録音のその範囲に音符・打楽器の音があるかで判定し、休みの本人には試聴ボタンを出さず、同じ位置に「この範囲は休み」と表示する。曲全体で休む本人は「この曲は休み」。顔・録音当時の名前・学年・席・G〜Sの力は保つ。
- 録音の「聴くパート」の選択肢にも、出番のある本人とパートだけを表示。音のない指定が残った場合は全員へ戻す。停止すると現在の部の通常の設定欄へ戻す。
- 本人の判定は演奏ごとのWeakMapに持ち、一度調べた音の対象を使い回す。音符・打楽器・録音・採点・成長・セーブ形式は変更しない。

説明文を追加で並べず、使えない試聴ボタンを短い休みの表示へ置き換えた。素材・フォント・動く演出の追加、外部からの取得はない。

## 確認

- `check_recording_rest.js`：全15曲・57範囲を実際に演奏へ変換。休みの延べ301人と音のある延べ1922人で、カードと試聴・パートの選択肢を照合。音符・打楽器の区別、無音の指定の解除、判定の使い回し、部・録音・演奏の不変、現在の設定欄の保持を確認した。
- 実ブラウザの前半の録音では39人の顔を残し、全員の音は18人分。休みのカードに試聴ボタンがなく、本人だけの指定にならない。音のあるオーボエは本人だけを聴ける。その後に休みのフルートを開くと全員へ戻る。
- 同じ録音のまま、ダブルリードの2人→全員の18人へ切り替えられる。再生idと演奏ハッシュ、部・録音の内容を保つ。
- 読み込み待ちでも休みの表示と出番のあるパートの一覧が出る。選んだパートはカードを閉じても保ち、解放後は意図した2人だけが鳴る。
- 曲全体の録音では休みの打楽器に「この曲は休み」を表示。出番のある打楽器だけの試聴は正常で、37人の全員の音を無音にしない。
- 375×812・375×667のライト・ダークで顔・ランク・休みが見え、横にはみ出さない。4タブもはみ出しなし。
- 50操作で2027年度へ進行。33スクリプトの読み込みに成功し、コンソール警告・エラーなし。
- 録音カード、個人録音の停止、現在の部員の試聴、当日の舞台の既存検証も合格。各`*-check.txt`に保存。
- 字の検査は既存の5記号（▶♩♮⤓𝄪）とコメントの「常」「了」を報告。今回の表示文言は本文の全3ウェイトに収録済み。

`browser-check.json`は各操作直後の観測。`before-final-range`は最初の録音が自然終了した後の状態で、再生中の証拠には使わない。画像は同じ部員を再生中に撮影した`rest-light-final`・`rest-dark-final`と、待機中の`wait-light`・`wait-dark`。
