# 部員の名前を変える

- 部員カードの名前の下に「名前を変える」を追加。カードの中で入力し、「保存する」で反映する。「やめる」とEscで取り消せる。
- 上限12文字。前後の空白を外し、連続する空白を1つにまとめる。文字・数字・空白と中点・長音・ハイフン・ピリオドを使える。空欄、長さ超過、同じ部にいる別人と同名、名前以外の記号は理由を表示して保存しない。
- 部員のidと能力・体力・経験・夢・関係・週は変えない。元の名前を `originalName` に残し、顔の配役を保つ。何度名前を変えても同じ顔を使い、顔と名前の生成方法はそれ以外では変えていない。
- 新しい名前は現在の名簿、練習、部員カード、これからの出来事に反映。過去の録音・日誌・思い出の文章はそのときのまま保つ。記録から本人を探すときは元の名前も使い、同名の別人がいる場合には顔を決めつけない。
- これから録る録音の控えにも元の名前を引きつぎ、録音時と現在で顔が変わらない。旧セーブは `load()` で元の名前を補う。保存先・セーブのバージョンは同じ。
- 名前を変える・保存・取り消しは44px以上、入力欄は48pxで文字は16px。長い名前はカードと名簿で全文を折り返し、毎週の練習は1行に収める。保存と取り消しのあともカードが見える位置を保つ。
- 素材・フォントのダウンロードなし。採点と成長の計算は変更なし。

## 確認

- `node tsukurikata/tools/check_member_names.js`：保存・再読み込み、旧セーブ、何度変えても同じ顔、能力とid、過去と新しい録音、空欄・12文字の境界・同名・記号を確認。
- 375pxのライトとダークで入力・保存・取り消しを確認。空欄と同名と13文字では保存せず、12文字では保存できる。Escと「やめる」は未保存の入力を戻す。
- 名簿と今週の練習に新しい名前が反映され、長い名前で4タブを開いても横幅は375pxに収まる。
- 名前を変えた1年生を4月から新年度まで50回の画面更新で進め、同じid・名前・顔を引きつぐことを確認。画面確認中のエラーなし。
- JavaScriptの構文、`check_faces.js`、`check_stage_faces.js`、`git diff --check` が成功。字のチェックは既存の不足記号5字のみで、新しい不足なし。
- iPhoneへのビルド・インストール・起動が成功。変更した4ファイルはアプリ内の同梱ファイルと一致。実機の見た目と日本語キーボードはオーナーが確認する。

画面の確認結果は `screenshots/checks.json`。確認ページは実際のゲーム処理を使うが、本物の保存先には書き込まない。iPhone用のビルドには `design/` を入れない。
