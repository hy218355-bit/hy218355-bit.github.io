# アンサンブルを、出場前に聴く

人選画面の下に46pxの丸い再生ボタンを追加。選んだ3〜8人の音を聴いてから出場を決められる。試聴中は停止の印になり、選び直すと止まる。出場・辞退と同じ一列に置き、固定操作の段を増やさない。

## 音と部員

- `ensemblePreviewPerf`は、本番と同じ曲（`contestPiece`優先）・市民会館・緊張3・本番前の能力／譜読み／体力で演奏を作る。`runEnsemble`は試聴に使わず、部員・評判・録音・日誌を変えない。
- 試聴は`U.ensListen`だけに覚える。選択変更、保存する操作、出場、辞退で止める。読み込み待ちを取り消した後も勝手に鳴らない。
- 停止・自然終了では、元の曲と練習区間へ戻す。別の自由曲を選んでいる場合も、試聴中はアンサンブルの曲を表示。範囲と指揮の操作は試聴中だけ無効にする。
- 今週タブでは手元に停止があるため、小さな再生バーを重ねない。他のタブでは同じバーから止められる。
- 読み込み中は丸い印と読み上げの文言を出し、同じボタンで中止できる。演出ふつうだけ印を回し、短く・なし・`prefers-reduced-motion`では固定する。
- 席のない人を選択から外す。12文字の名前は折り返し、チェックの場所を空ける。

ゲーム・採点・成長・音源の式とセーブの形は変更していない。

## 確認

- `node tsukurikata/tools/check_ensemble_preview.js`：全15曲×3・5・8人の45編成。本番の録音と試聴の音符・時刻・音程・音量が完全一致。選択した部員だけが演奏し、入力した部の全データが不変。席のない人・存在しない人の選択整理も確認。
- `browser-check.json`：実画面の375pxライト・ダーク、2人で無効、8人上限、選び直しで停止、別タブの停止、自然終了と元の曲／区間への復帰、読み込み中止後の遅延再生なし、改名後の停止、出場・辞退を確認。
- 実画面で7人の試聴から出場し、保存された本番の演奏とのハッシュ一致を確認。試聴は`SampleVoice`で鳴らした。
- 読み込み中に演出ふつうからなしへ変え、印のCSSアニメーションが`ensloading`から`none`へ変わることと、部の状態が不変であることを確認。
- 50操作で2027年度まで進行。33スクリプトすべて読み込み、起動失敗・コンソール警告・エラーなし。
- 記録の照合は`browser-assertions.txt`。ライトの主画像は5人、ダークは3人を選んで実際に試聴中。小さい画面は375×667、12文字の名前と読み込み中の表示。
- 指揮の予告・入力時刻、結果発表の操作の既存検証も合格（各`*-check.txt`）。
- 字の検査は既存の不足5字（▶♩♮⤓𝄪）のみ。今回の追加文言による不足なし。フォントの取得・作り直しなし。
