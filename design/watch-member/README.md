# 本番の部員カードから、安心して舞台へ戻る

本番を聴く画面の顔カードを確認すると、閉じても本人だけの音が残り、Escapeではカードと一緒に本番ごと閉じていた。本人の音を切り替えるたびにボタンを作り直して操作先がbodyへ落ち、選択中を示す`aria-pressed`もなかった。指揮をしない本番にも空のテンポ欄が出ていた。修正前の実画面の値は`before.json`。

## 変更

- カードを閉じる・別の部員を開くと、全員の音へ戻す。閉じても演奏や結果発表を進めず、操作先と表示位置を舞台へ戻す。
- Escapeは、説明があれば説明、カードがあればカードを先に閉じる。本番を閉じる操作と分ける。
- `toggleCdMemberSolo`で同じボタンの文言・選択の枠・`aria-pressed`だけを更新する。カードや顔を作り直さず、ボタンの操作先と読んでいる位置を保つ。
- 次の曲では選択した部員とカードを消し、全員の音で始める。指揮へ切り替えた場合も古いカードを残さない。
- カードの閉じる・試聴を44px以上にし、本番を聴くだけの画面から空の指揮用テンポ欄を隠す。名前の領域をカードの読み上げ名として結ぶ。
- 点数・伸び・演奏の音づくり・録音・セーブ形式は変更しない。素材・フォントの取得なし。

## 確認

- 375×812のライト・ダークで、実際のA部門の課題曲と自由曲を再生。`SampleVoice`で鳴り、本人だけの音へ切り替えても同じ再生のまま続く。カードのボタンは44px、横幅は375px内。
- Escapeでカードだけが閉じ、音は全員へ、操作先は舞台へ戻る。演奏は続き、発表待ちの結果は未発表のまま。別の部員を開いたときも、前の本人だけの音が残らない。
- キーボードのSpaceでも本人だけの音へ切り替えられ、操作先は同じボタンに残る。両テーマの実画面をPNGへ記録。
- 課題曲でカードを開き、本人だけの音にしたまま自然終了を待つ。自由曲ではカードが閉じ、全員の音へ戻って再生が続く。自然な本番終了では結果発表へ進み、カードの操作で部員と録音の内容は変化しない。
- 説明とカードが両方開いている場合は、Escapeで説明だけが閉じる。カードの「閉じる」でも舞台へ戻り、本番画面は残る。
- 375×667で12文字の名前を表示。名前を省略せず折り返し、44pxの閉じる・試聴とカードが画面内に収まる。両テーマをPNGへ保存。
- 本番画面を閉じて通常の指揮を開き直すと、カードは非表示・全員の音・タップ面に操作先がある。確認ページの早送りは49進行で4月から新年度2027年へ到達。起動33/33、エラーなし。
- 指揮の予告・2/3/4/8拍・全15曲の区間・テンポ出しの中断・入力待ち補正・保存した指揮は既存の回帰確認が通る（`cue-check.txt`・`timing-check.txt`）。字の確認は既存の未収録5記号のみ（`glyph-check.txt`）。
- Release版をミラーリングなしでiPhoneへ導入。HTML・指揮・UIの同梱ファイルは一致。端末がロック中のため、今回は起動と実行プロセスは未確認（`iphone-check.json`）。実機の画面・音・操作感はオーナーが確認する。
