# 会いたい部員を、すぐ見つける

## 変更

- 名前・学年・楽器を組み合わせて名簿を絞れる。表示人数を添え、「すべて表示」で一度に戻せる。
- 名前の間の空白を省いても見つかる。全角・半角、かな・カナ、英字の大文字小文字もそろえて探す。漢字の読み方を推測する機能は足していない。
- 楽器は既存の自作アイコンから選ぶ。控えも選べる。金の枠とチェック、`aria-pressed`で選択を示す。
- 名簿の顔が先に見えるよう、9パートの全体のランクは「パートのようす」で開く形へまとめた。パートの印から合奏の音の動きへ移る操作は保持。
- 名前の入力欄と学年のボタンは作り直さないので、入力位置を保てる。日本語の変換中は確定を待ち、Enterで最初の部員へ、もう一度Enterでカードを開ける。同じ検索値のイベントで行を作り直し、移動先のフォーカスを消してしまう問題も防いだ。
- タブ移動・カードの開閉で条件を保ち、閉じたら元の部員へ戻す。改名などで条件から外れたら検索欄へ戻る。新しい部と新年度では全員表示へ戻す。
- 320pxでも、Enterで移った部員や楽器一覧の最後の選択が下のタブバーに隠れない余白を確保。入力は16px、操作は44px以上。

名簿の条件はUIのメモリだけに持ち、セーブ形式はそのまま。絞り込んでも本番の編成・採点・成長・音を変えない。虫眼鏡だけ自作SVGを追加し、色は`currentColor`を使う。素材・フォントのダウンロードなし。新しい画面の文言による不足字形もなし。

## 確認

実ゲームの画面とスクリプトを使い、確認ページだけは本物のセーブと設定を保存しない。最終版は`qa-roster-find-4`。

- `browser-check.json`に37場面と、学年4条件・3年生×楽器11条件の15通りを記録。表示されたidを実際の部員・学年・楽器と比較し、一致。条件を変えても部の状態は一致。
- 375×812のライト・ダークで、全員、名前、学年と楽器の組み合わせ、部員カード、空の結果を確認。4タブの移動でも条件と部の状態を維持し、内容幅375px。
- `田中七海`で`田中 七海`、`ｻﾄｳﾊﾙ`で`さとう はる`、`akiあおい`で`Ａｋｉ あおい`が見つかる。入力欄のフォーカスと入力位置も保持。
- 名前の消去・Escapeでは学年と楽器の条件を保つ。楽器を開いたときのEscapeは、その選択欄だけを閉じる。
- Enterで名前から最初の行へ移り、カードを開ける。カードを閉じた後は元の本人と条件へ戻る。
- 本人の試聴を始め、カードを閉じたあとも同じ再生を保って絞り込める。カードを閉じると全員の音へ戻る既存の動作はそのまま。
- 12文字に改名して条件から外れた後も検索欄へ戻り、新しい名前で同じid・顔が見つかる。控え・部員0人も表示できる。
- 320×568で長い名前の行全体と楽器一覧の最後の「控え」が、下のタブバーより上に収まる。
- 初年度を実際の69操作で2026年4月から2027年4月まで進行。条件は年度内で保ち、新年度では入力欄が空・全学年・全楽器の8人表示へ戻る。コンソールの警告・エラーなし。
- 顔100人・舞台の顔と楽器・個人録音の停止・卒業の保存と移動の既存チェックが成功。JavaScriptの構文と差分も確認。字形チェックは既存の不足記号5字のみ。

年度の記録は`year-flow.json`、両テーマの4タブは`tabs-check.json`、コンソールは`console-check.json`。画像はすべてPNG・200KB以内。通常375×812、小さい画面の見本だけ320×568。
