# 顔の画質・名前との組み合わせの修正

2026年10月26日。オーナーの実機での指摘を受けて、39人を描き直した。「今の名前を残し、顔を合わせる。新入部員から女性4：男性1にする」の返答に合わせた。作業は `codex/design` の別worktree。pushなし。

[名前つきの見本と39人を見る](index.html)

## 変更

- 前の顔は224px・40色のSVG変換で線と肌が粗くなっていた。今回は描き直した原画を、元の画素数のままWebPへ圧縮。減色パレット・SVG化・顔ごとの画像複製を使わず、3枚の絵をCSSで表示する。
- 初々しい美男・美女として女性31人・男性8人を制作。小さくすると男性に見えやすかった短髪の女性3人は、顔まわりの髪と表情を個別に調整した。
- 1枠は約324〜362px。カードの112px（枠の内側106px）をiPhoneの3倍密度でも補える画素数を保つ。画像は194,512／196,002／197,882 bytes、合計588,396 bytes。以前の39組のSVG・読み込みJSは同梱から除いた。
- この作品の既存の名前リストを、顔の配役へ対応させた。曖昧な名前は作品内の配役として固定し、現実の人の性別の判断には使わない。今いる部員、入部待ちの部員、卒業生の名前や記録は書き換えない。
- 新しく作る名前だけ、通し番号の5人に女性4人・男性1人の名前を割り当てる。選ぶ名前は従来と同じリストの範囲。顔はidと名前の配役から決まり、進級や画面の切り替えで変わらない。
- セーブに性別・顔の情報を足さない。点数・成長・イベント・セーブ形式は変更なし。`band.js` の変更は名前生成と配役表だけ。
- 名前と顔の変更をWeb側でもすぐ反映できるよう、変更したスクリプトと原画のURLに版番号を付けた。
- iOSの同梱ファイル配信にWebPのMIME型を明記した。

## 制作と出典

組み込みimage_genを使用。初回の3枚と、短髪の女性3人だけを調整する最終プロンプトは [prompts.json](prompts.json)。最終原稿のパス、画素数、圧縮品質、容量は [manifest.json](../../tsukurikata/img/faces/manifest.json)。`tools/build_faces.py` で圧縮のみを行った。外部作品・ダウンロードは使っていない。出典は [CREDITS.md](../../tsukurikata/img/CREDITS.md)。
