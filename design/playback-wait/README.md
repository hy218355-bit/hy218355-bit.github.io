# 音源を待つあいだも、これから鳴る曲と本人を表示する

## 見つかった不一致

5人の「歓喜の歌」の試聴を読み込み待ちにした後、合奏タブを開くと、前の曲「天国と地獄」と39人の顔が残っていた。指揮と範囲も有効なまま。20ms後の`refreshNow`が待機を通常の停止と扱い、待機の説明を「表示中：いまの音」へ上書きしていた。修正前の実画面は`before.json`と`screenshots/before-light.png`。

## 変更

- `playPerf`は待機を作った時点で、待っている演奏・表示名・当時の部員をそろえ、曲と舞台を描く。`refreshNow`は次の通常合奏を作るが、再生中と待機中の表示は上書きしない。
- 待機中の表示は従来の「録音を読み込んでいます…（読み込めたら鳴ります）」を使い、画面の文章は増やさない。
- アンサンブルは選んだ5人だけを待機中から舞台に出し、曲名をそろえる。指揮と範囲は試聴中と同じく無効。
- 昔の録音は待機中から当時の曲・区間・部員を表示する。舞台の顔から当時のカードを開き、改名・席替えを出さない。今同じ席にいる別の部員に取り違えない。
- 中止では当時のカードを閉じ、今の部と曲へ戻す。本番の終了処理は呼ばない。中止の通知の中で次の演奏や待機を始めた場合は、それを消さない。
- 今いる部員の試聴に切り替えるときも、前の人選の待機を先に止める。アンサンブルの一時的な選曲を元に戻してから、今の本人の音を作る。

ゲーム・採点・成長・音源・録音内容・セーブの形は変更していない。新しい素材やフォントの取得なし。動く演出の追加なし。

## 確認

- 375×812のライト・ダーク：5人で「歓喜の歌」を待機、前の曲が表示されない、顔5人、範囲と指揮が無効、読み込みの文が残る。
- 中止後は今の曲と39人へ戻り、読み込み完了後も勝手に鳴らない。同じ部の全データと録音が不変。
- 375×667の昔の録音：新世界の「前半」を待機し、当時の田中七海・3年・ピッコロ・Aランクのカードを開いた。現在は同じidの田中花音が打楽器の席にいる確認用データでも、混同しない。中止で当時のカードを閉じる。
- 待機中に2026年度の録音から2027年度の録音へ切り替え、後の録音だけを`SampleVoice`で再生。待機と再生の演奏ハッシュは保存した録音と一致。部の全データと録音は切り替え・再生・停止を通して不変。
- アンサンブルの待機から名簿の山口大翔を試聴。元の自由曲へ戻り、古い人選を解消して、実際にその本人だけが鳴る。部の全データは不変。
- 49操作で2027年度へ進行。33スクリプトの起動失敗、コンソール警告・エラーなし。
- `browser-check.json`に実画面の値、`browser-assertions.txt`に記録の照合結果を保存。
- `check_member_record_stop.js`：待機中の演奏・当時の部員、取り消し後の予約無効化、本人指定の復帰、中止の通知が始めた次の再生と次の待機を保つ。
- `check_current_member_listen.js`：待機中の別の人選から今の本人へ切り替える。現在の再生中の切り替えは止めない。
- `check_stop_current.js`：20ms後の再構築で待機中の演奏と名前を上書きしない。停止後の今の音、終了の一回実行、次の本番も保つ。
- `check_audition_listen.js`：選択・全員・本人の試聴、待機中止、自然終了と保存の不変。
- `check_ensemble_preview.js`：全15曲×3・5・8人の45編成で本番と一致。
- 字の検査は既存の不足5字（▶♩♮⤓𝄪）のみ。追加の不足なし。

ミラーリングなし。`codex/design`、pushなし。
