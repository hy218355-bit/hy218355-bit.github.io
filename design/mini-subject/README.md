# 小さい再生バーにも、聴いている本人を

別タブの再生バーは、本人だけを聴いていても「いまの音」とだけ表示し、対象が分からなかった。`before.json`は表示と顔0人、40pxの停止ボタンの記録。

## 変更

- 本人の試聴は、28pxの顔・そのときの楽器・名前と曲名を1行で表示。パートの試聴はパート名と曲名を表示する。全員では従来の演奏名を残す。
- 実際の`E.solo`と再生・待機の演奏から表示する。録音は、その演奏に覚えてある当時の本人を優先し、現在の改名・席替えと混ぜない。
- `applySolo`で音の指定とバーを同時に更新。表示内容が同じときは顔とSVGを作り直さない。既存の画像とSVGを使い、追加の画像・フォント・外部取得はない。
- 長い名前は横にはみ出さず、読み上げには全文と合奏を開く操作を残す。バーを押すと合奏へ戻り、同じ演奏を続ける。開く操作と停止を44px以上にそろえる。

練習・成長・採点・譜面・音・録音・セーブ形式は変えていない。表示のメモはUIだけに置く。バーを隠す条件と、停止後の操作先も保つ。動く演出は追加していない。

## 確認

- `check_mini_subject.js`で全15曲を確認。録音の本人の顔と当時の楽器、パート、全員、待機、停止、合奏タブ、人選中、表示の使い回し、名前の安全な表示、部と演奏の不変を確認した。
- 実ブラウザ14状態で、顔と対象が本人1人・パート4人・全員39人の実際の音に一致。同じ再生idを保ち、バーから合奏へ戻る・停止ができる。部と録音のハッシュは変わらない。
- 現在は「田中 花音／パーカッション2」の本人も、2027年の録音では「田中 葵／ピッコロ」と表示する。顔のidだけでなく、原画を描くCSSも録音時の本人と照合した。
- 12文字の名前と読み込み待ちを375×667で確認。待機のあとも同じ本人を再生し、表示中のバーでパート・本人を切り替えられる。
- 375×812のライト・ダーク。開く・停止は44px以上、横にはみ出さず、週送りと下のタブに重ならない。49操作で2027年度へ。33スクリプト起動成功、4タブ375px。最後の確認でコンソール警告・エラーなし。
- 現在の本人・録音の休み・今の部の休み・お手本・選曲の試聴・停止後の操作先・オーディションなど8種類の既存検証も合格。既存検証は描画の依存先だけ補い、元の判定は保つ。
- 字の検査は既存の記号とコメントの8字を報告。今回の表示に必要な字は同梱済みで、フォントは変えていない。

`browser-check.json`は現在の部と待機、`record-browser-check.json`は録音の操作。QAは本物のセーブと設定を変えない。各画像と検証ログは同じフォルダに保存した。
