# 名前と、席を決める操作を読みやすく

375pxの席選びで顔とチェックが名前の幅を削り、「小川 悠／斗」のように途中で折れていた。480px以下では36pxの顔の下に名前と席を置き、9楽器の通常の候補名をすべて1行で表示できるようにした。長い名前は小さくせず、全文を折り返す。顔の画像と大きさは変えていない。

確定ボタンは選んだ結果に合わせて「交代する」「控えにする」「この席へ移す」に切り替える。未選択へ戻すと「移す」と灰色の無効状態へ戻る。説明文を増やさず、移動・交代・能力変化・セーブ・取り消しの処理はそのまま。

## 確認

- 375pxのライト・ダーク、4タブ、合奏と部員一覧から開くカードで横はみ出しなし。
- 9楽器の候補名の高さはすべて18pxの1行。顔は36×36pxで縦横比を保持。楽器の切り替えでは部の状態を変えない。
- 交代・控え・空席で文言が一致。決定した席と能力が、選択時の予告と一致。「元に戻す」で部の状態を復元し、録音も保持。
- 再タップ・楽器の切り替えで文言と無効状態を戻す。Enterで選び、Spaceで解除し、Escapeで中止しても部の状態は不変。
- 320×568pxで12文字の名前を2行で表示。選択のチェックと重ならず、顔も36×36px。再生中の停止を含む3ボタンは44px以上で、交代の予告は固定ボタンに隠れない。
- 本番中は移動先を選んでも確定できない。
- `node tsukurikata/tools/check_member_move_undo.js`成功。構文確認成功。フォントの不足は従来の記号5字だけ。
- 画面エラー・スクリプト読込失敗なし。33スクリプトをすべて読み込み。コンソール警告・エラーなし。
- iPhone用の署名付きReleaseビルド成功。変更したHTMLとui.jsが同梱内容とSHA-256で一致。実機へのインストールと表示は未確認。直前の録音一覧の改善で確認した実機の接続状態はunavailable。

記録は`browser-check.json`・`console-check.json`・`iphone-check.json`・`glyph-check.txt`。確認ページは本物のセーブと設定を書き換えない。画像は実際の375×812pxと320×568pxのPNGで、表示内容は加工していない。
