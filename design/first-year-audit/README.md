# 初年度の通し確認と、年度末・停止後の表示

- 合奏を聴きながら週を進めて停止すると、前の週の見出しと譜面が残っていた。終了後は録音の場合に限らず現在の演奏を作り直す。終了の通知や、次の演奏を始める処理は保持。
- 冬の合奏の日付を11月・1月・3月にする共通のnowWhenを使う。練習の指揮を録音するときの新しいラベルにも使う。以前の録音のラベルは書き換えない。
- 3年生がいない年度の選曲と今後の日誌で「3年生の最後の本番」と書かない。3年生がいる年は従来の案内。過去の日誌の文章はそのまま。
- 年度末の「いちばん伸びた」は、増えた能力の数から、顔とG〜Sの前後のランクへ変更。内部の選び方と順位はそのまま。スキル・行事の本文は開いて確認できる。
- 新年度へ進むボタンをスマホの画面下に置く。録音中は小さな再生バーの上へ寄せ、ほかのタブでは表示しない。

素材・フォントの取得なし。採点・成長の式、セーブ形式は変更なし。
